# Snakes Slither: premium UI ("Jungle at dusk")

The approved visual direction for the whole app (2026-10-31). It replaces the light cream look of the earlier UI canvas and the old app.

Related docs: [UI canvas (earlier)](../ui_canvas/README.md) · [Brand assets](../brand/README.md) · [06 UI/UX Screens](../../phases/phase_1/06_UI_UX_SCREENS.md) · [UI tasks](../../handoff/UI_TASKS.md)

| File | What it is |
|---|---|
| `BRAND_BOOK.md` | The rules: principles, voice, colour, type, spacing, icons, motion, layout and flow |
| `tokens.json` | Every colour, type style, spacing step, radius and shadow, with a usage note on each |
| `icons/glyphs/*.svg` | 23 UI glyphs, 24 × 24, single ink `#EEF5EF` (tintable) |
| `icons/game/*.svg` | 10 full-colour game icons, 48 × 48 (coin, heart, star, hint, shield, hammer, gift, trophy, crown, wheel) |
| `components/*.md`, `components.css` | Component specs: Button, IconButton, HudPill, BoosterButton, Card, Popup, LevelNode, BoardSample |
