# LevelNode

A stop on the Level Map's vine path.

- 64px disc. **cleared**: `emerald` + its best stars below; **current**: `gold` with a soft gold halo that pulses (1.6 s, off with reduced motion) and Pip beside it; **hard**: an `ember` ring; **locked**: `moss` + `lock` glyph, not tappable; **milestone**: the `gift` icon.
- Numbers in `hud-number`. Tapping an unlocked node opens the level start sheet.
