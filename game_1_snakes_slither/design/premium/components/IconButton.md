# IconButton

A 48px round button carrying one UI glyph: pause, back, close, settings, info.

- Fill `canopy`, shadow `elev-1`, glyph 24px in `mist`. Hit area never smaller than 48 × 48.
- Use for navigation and utility only, never for the main action (that is a `Button`).
- Always give it a screen-reader label ("Pause", "Back").
