# Spec Groups

Use these group folders under specs/ so specs stay easy to find. Create a new group only if none fits.

- gameplay: core rules, mechanics, obstacles, level progression
- economy: boosters, coins, shop, rewards, ads, VIP
- meta: daily challenge, streak, LiveOps, album, star race
- ui: screens, flows, onboarding, art direction, VFX and game feel
- tech: frontend, offline and cloud sync, performance, logging, QA
- audio: sound effects and music
