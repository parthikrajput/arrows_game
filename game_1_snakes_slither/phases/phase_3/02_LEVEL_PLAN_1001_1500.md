## 1. Principles (સિદ્ધાંતો)
1. **50 Blocks × 10 Levels = 500 Levels:** દરેક block `(B-1)*10 + 1` થી `B*10` સુધી ચાલે છે.
2. **Fixed Difficulty Plateau (D 60–76):** દરેક block માં D-band 60 થી 76 ની વચ્ચે જ રહે છે. Block ની અંદર x1 intro (low ~60-63), x5 breather (easy ~58-61), x9 hard (hard ~80-84) અને x0 milestone (gift basket).
3. **Slot Mapping Rule (standard §17.38):**
   - **Block 1 x1 (L1001):** Signature System Intro (Day & Night Cycles).
   - **Block 2 x1 (L1011):** Base Mechanic 1 — M101 Sun-Moon Gate.
   - **Block 14 x1 (L1131):** Base Mechanic 2 — M102 Moonlight Root Bridge.
   - **Block 26 x1 (L1251):** Base Mechanic 3 — M103 Day-Night Burrows.
   - **Block 38 x1 (L1371):** Base Mechanic 4 — M104 Twilight Flower Gate.
   - **Blocks 3–13, 15–25, 27–37, 39–49 (45 Blocks):** 45 Variants (Base Mechanics × Modifiers).
   - **Block 50 x1 (L1491):** Review Level / "Mastery Mix" (કોઈ નવું item નહીં; standard §17.34).
   - **Block 50 x0 (L1500):** Phase 3 Finale ("Day & Night Temple") + Jungle Treasure Chest.

## 4. Finale Level 1500 Details
- **Name:** "Day & Night Temple"
- **Grid:** 14×14 (3 Layers).
- **Paths ($P$):** 38 snakes.
- **Mechanics Pool:** M101 (Sun-Moon Gate) ×2, M102 (Moonlight Bridge) ×2, M103 (Day-Night Burrows) ×1 pair, M104 (Twilight Flower Gate) ×2, M098 (Prowling Mongoose) ×1, M053 (Rolling Coconut) ×2.
- **Difficulty ($D$):** Target ≈ 91 (Plateau high $76 \times 1.2$).
- **Reward:** Jungle Treasure Chest (1,000 coins + 2 Hint + 2 Shield + 2 Hammer + Phase 3 Master Badge).
