## 1. Principles (સિદ્ધાંતો)
1. **50 Blocks × 10 Levels = 500 Levels:** Levels 2001 થી 2500.
2. **Fixed Difficulty Plateau (D 60–76):** પઝલની મુશ્કેલી બ્લોક્સની સંખ્યા કે સાપ વધારવાથી નહીં પરંતુ પુશ ફિઝિક્સના ક્રમિક લોજિકથી આવે છે.
3. **Slot Mapping Rule (standard §17.38):**
   - **Block 1 x1 (L2001):** Signature System Intro (Coconut Grove Physics).
   - **Block 2 x1 (L2011):** Base Mechanic 1 — M201 Coconut Pit.
   - **Block 14 x1 (L2131):** Base Mechanic 2 — M202 Dew-Slick Coconut.
   - **Block 26 x1 (L2251):** Base Mechanic 3 — M203 Key Coconut.
   - **Block 38 x1 (L2371):** Base Mechanic 4 — M204 Jackfruit Boulder.
   - **45 Variant Blocks:** x1 slots of blocks 3–13, 15–25, 27–37, 39–49.
   - **Block 50 x1 (L2491):** Review Level / "Mastery Mix" (કોઈ નવું item નહીં).
   - **Block 50 x0 (L2500):** Phase 5 Finale ("Ancient Coconut Shrine") + Jungle Treasure Chest.
