## 1. હેડ્સ-અપ ડિસ્પ્લે (HUD) અને કી ઇન્વેન્ટરી સિસ્ટમ

Phase 16 ના એડવાન્સ્ડ કી-ક્રાફ્ટિંગ અને ચેઇન્સ માટે HUD માં નીચેના વિશિષ્ટ ઘટકો ઉમેરવામાં આવ્યા છે:

```
+-----------------------------------------------------------------------+
| [PAUSE]   LEVEL 7850 (Normal)        MOVES: 19       [COINS: 44,100] |
+-----------------------------------------------------------------------+
|  [KEY CRAFT: 🧩 HALF-A OK | HALF-B PENDING]    [SKELETON KEYS: 1]     |
+-----------------------------------------------------------------------+
|                                                                       |
|                       [ VAULT GAME GRID ]                             |
|          (M751 Key Vine & M754 Key Swap Pedestal active)              |
|                                                                       |
+-----------------------------------------------------------------------+
|  [HINT (150)]       [SHIELD (200)]       [HAMMER (250)]       [RETRY] |
+-----------------------------------------------------------------------+
```

### મુખ્ય UI ઘટકો:
1. **Key Crafting Ribbon:** સ્ક્રીનના ઉપરના ભાગે અર્ધ-ચાવીઓની સ્થિતિ (Part A: 🟢 Ready, Part B: 🟡 On Board) દર્શાવતી પઝલ-પીસ બેનર.
2. **Golden Vine Connection Line:** M751 માં તાળું અને જોડાયેલી ચાવી વચ્ચે ચમકતી સોનેરી વેલાની રેખા સ્પષ્ટ દેખાય છે જેથી ખેલાડી જાણી શકે કે કયું તાળું કઈ ચાવી મુક્ત કરશે.
3. **Skeleton Key Badge:** સ્કેલેટન કી ધરાવતા સાપના માથા પર વિશાળ સુવર્ણ પાંદડી ચમકે છે.
4. **Key Swap Pedestal Glow:** જ્યારે બે સાપ પેડેસ્ટલ પાસે આવે છે ત્યારે સ્ટોન પલ્સિંગ લાઇટ સાથે સક્રિય બને છે.

## 2. વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX & SFX Mapping)

| ઇવેન્ટ / ક્રિયા | વિઝ્યુઅલ ઇફેક્ટ (VFX) | ઓડિયો પ્રભાવ (SFX) | હેપ્ટિક ફીડબેક (Haptics) |
| :--- | :--- | :--- | :--- |
| **M751 Vine Lock Release** | તાળું ખુલતાં જ વેલો ઓગળીને નવી ચાવી પર સોનેરી સ્પાર્કલ્સ ફેંકે છે (`key_vine_dissolve`). | સુરીલો ધાતુનો રણકાર અને વેલાનો સળવળાટ (`sfx_vine_key_snap.ogg`). | મીડિયમ ક્લિક (Medium Pulse). |
| **M752 Key Crafting Forge** | બંને અર્ધ-ચાવીઓ UI માં જોડાઈને ચમકતી સંપૂર્ણ ચાવી બને છે (`key_crafting_forge`). | સોનેરી એરણ પર હથોડી અથડાવાનો સૂર (`sfx_key_anvil_clink.wav`). | ડબલ હેપ્ટિક ટિક (Double Tap). |
| **M753 Skeleton Key Unlock** | સ્કેલેટન કી તાળાને અડતાં જ તાળું સોનેરી પ્રકાશમાં વિખેરાઈ જાય છે (`skeleton_key_shatter`). | ભવ્ય પ્રાચીન તાળું ખુલવાનો ગૂંજતો અવાજ (`sfx_skeleton_unlock.wav`). | શાર્પ હેપ્ટિક ક્લિક (Sharp Tap). |
| **M754 Key Swap Trade** | બંને સાપો વચ્ચે ઊર્જાનું ચક્ર ફરીને ચાવીઓ બદલાય છે (`key_swap_beam`). | રહસ્યમય કંપન સૂર (`sfx_key_swap_woosh.wav`). | લાઇટ વાઇબ્રેશન (Light Pulse). |
| **Locked Gate Bonk** | ચાવી વગર તાળા સાથે અથડાતાં સાપ અટકીને પાછો વળે છે (`lock_recoil_spark`). | તાળા પર માથું પછડાવાનો સામાન્ય અવાજ (`sfx_lock_rattle.wav`). | એરર વાઇબ્રેશન (Failure Buzz). |
| **Level 8000 Grand Finale** | સમગ્ર તિજોરીના દરવાજા ખુલીને 10,000 સુવર્ણ ચાવીઓનો ભવ્ય વરસાદ (`vault_keys_grand_burst`). | વિજયી સુવર્ણ ફેનફેર ઓર્કેસ્ટ્રા (`sfx_vault_finale.ogg`). | સળંગ સેલિબ્રેશન વાઇબ્રેશન. |

## 3. એક્સેસિબિલિટી અને કલરબ્લાઇન્ડ સપોર્ટ (Accessibility)

- **Puzzle-Notch Shape Matching:**
  - અર્ધ-ચાવીઓ પર માત્ર કલર આધારિત મેચ નથી; Part A પર બહિર્ગોળ ખાંચો (Convex Notch) અને Part B પર અંતર્ગોળ ખાંચો (Concave Notch) સ્પષ્ટ દૃશ્યમાન હોય છે.
- **Key Hierarchy Badges:**
  - સામાન્ય ચાવી = પિત્તળ (Bronze), અર્ધ-ચાવી = ચાંદી (Silver), સ્કેલેટન કી = શુદ્ધ સોનું (Gold) સાથે અલગ ગ્લો પેટર્ન.
- **High-Contrast Vine Tracing:**
  - ચાવી અને તાળાને જોડતી વેલાની લાઇન 2px ઘેરી આઉટલાઇન સાથે રેન્ડર થાય છે જેથી બેકગ્રાઉન્ડ સાથે ભળી ન જાય.

## 4. પર્ફોર્મન્સ બજેટ્સ અને ઑપ્ટિમાઇઝેશન (Performance Budgets)

Phase 16 ના ક્રાફ્ટિંગ એનિમેશન્સ અને પાર્ટીકલ્સ માટે કડક ફ્રેમરેટ મર્યાદાઓ:

| ડિવાઇસ ટિયર (Device Tier) | મહત્તમ એકસાથે પાર્ટિકલ્સ | ટાર્ગેટ ફ્રેમરેટ (FPS) | બોર્ડ જનરેશન બજેટ | મેમરી હેડરૂમ |
| :--- | :---: | :---: | :---: | :---: |
| **Low-End Tier** (Android Go, 2GB RAM) | $\le 30$ particles | 60 FPS (min 50 FPS) | $\le 250\text{ ms}$ | $\le 90\text{ MB}$ |
| **Mid-End Tier** (4GB RAM) | $\le 80$ particles | 60 FPS | $\le 200\text{ ms}$ | $\le 110\text{ MB}$ |
| **High-End Tier** (Flagship devices) | $\le 150$ particles | 60–120 FPS | $\le 150\text{ ms}$ | $\le 130\text{ MB}$ |

- **UI Texture Atlasing:** ચાવીઓ અને તાળાઓના તમામ આઇકન્સ એક જ શેર કરેલી સ્પ્રાઇટ શીટમાં રાખવામાં આવ્યા છે.
- **Level Generation:** L7501–8000 નું જનરેશન $300\text{ ms}$ ની અંદર પૂર્ણ થાય છે.

## 5. ક્વોલિટી એશ્યોરન્સ ટેસ્ટિંગ ચેકલિસ્ટ (QA Checklist P16-QA-01 to P16-QA-10)

Phase 16 ના ઉત્પાદન સ્તરે પરીક્ષણ માટે નીચે મુજબના 10 ટેસ્ટ પાસ થવા અનિવાર્ય છે:

- [ ] **P16-QA-01 (M751 Chain Cascade):** તાળું 1 ખુલતાં જ વેલો યોગ્ય રીતે ઓગળીને ચાવી 2 ને મુક્ત કરવો જોઈએ.
- [ ] **P16-QA-02 (M752 Half-Key Crafting):** બંને અર્ધ-ચાવી સાપો સંપૂર્ણ બહાર નીકળે ત્યારે જ નવી ચાવી ક્રાફ્ટ થવી જોઈએ.
- [ ] **P16-QA-03 (M753 Skeleton Priority):** સ્કેલેટન કી સાપના પાથમાં આવતા પ્રથમ બંધ દરવાજાને તાત્કાલિક અનલૉક કરવી જોઈએ.
- [ ] **P16-QA-04 (M754 Swap Stone Action):** બે સાપો વચ્ચે ચાવીઓ સફળતાપૂર્વક અદલાબદલી થવી જોઈએ અને 1 મૂવ વપરાવો જોઈએ.
- [ ] **P16-QA-05 (Zero Damage on Locked Gate):** ચાવી વગર તાળા સાથે અથડાતાં કોઈ હાર્ટ ન કટ થવું જોઈએ (0 Hearts Lost).
- [ ] **P16-QA-06 (No Circular Deadlocks):** લેવલ જનરેટ કરતી વખતે ચાવીઓની નિર્ભરતામાં ક્યારેય સાયકલ ન હોવી જોઈએ.
- [ ] **P16-QA-07 (Undo Key Inventory Integrity):** Undo કરવાથી ક્રાફ્ટ થયેલી ચાવીઓ અને સ્વેપ થયેલા ટોકન્સ પાછલા સ્ટેટ પર આવવા જોઈએ.
- [ ] **P16-QA-08 (Level 8000 Finale):** લેવલ 8000 પર સમગ્ર સુવર્ણ તિજોરી ક્લિયર થઈને ગ્રાન્ડ ચેસ્ટ એવોર્ડ થવી જોઈએ.
- [ ] **P16-QA-09 (Memory Leak Check):** સળંગ 50 કી લેવલ્સ રમીને રીસ્ટાર્ટ કરતાં મેમરી વપરાશ 120MB થી વધુ ન વધવો જોઈએ.
- [ ] **P16-QA-10 (CI Binary Verification):** `phase_16_meta.bin` ફાઇલનું સાઇઝ વેરિફિકેશન અને ચેકસમ માન્ય હોવું જોઈએ.
