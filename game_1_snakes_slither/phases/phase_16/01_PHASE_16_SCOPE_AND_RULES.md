# Phase 16: Scope and Rules (લેવલ 7501 થી 8000)

> આ દસ્તાવેજ **Phase 16 (Treasure Keys: Keys Deluxe)** નું કાર્યક્ષેત્ર, એન્જિન નિયમો, ચાવી-આધારિત નિર્ભરતા ગ્રાફ (Key-Dependency DAG), ગ્રીડ મર્યાદાઓ અને ડિફિકલ્ટી બેન્ડ નિર્ધારિત કરે છે.

**Related docs:** [Phase 16 Index](./README.md) · [Shared Core Standard §11, §12](../../SHARED_CORE_STANDARD.md) · [Scaling to 10,000 §2–§6](../../SCALING_TO_10000_LEVELS.md)

## 1. ક્ષેત્ર અને હેતુ (Scope & Objective)
Phase 16 માં ખેલાડીઓ જંગલના પ્રાચીન ખજાના અને તાળાઓ (Treasure Keys) ની સિસ્ટમમાં પ્રવેશ કરે છે. આ તબક્કામાં સામાન્ય ચાવી-તાળાની બહાર જઈને જટિલ ચાવી-નેટવર્ક રજૂ થાય છે:
- શૃંખલાબદ્ધ તાળાઓ જ્યાં એક તાળું ખુલતાં નવી ચાવી પ્રગટ થાય છે (M751 Key Vine).
- બે અર્ધ-ચાવીઓને ભેગી કરીને સંપૂર્ણ ચાવીનું નિર્માણ (M752 Key Crafting).
- કોઈપણ પ્રથમ તાળાને તોડતી સાર્વત્રિક ગોલ્ડન સ્કેલેટન કી (M753 Golden Master Leaf).
- સાપો વચ્ચે ચાવીઓની અદલાબદલી કરાવતી સ્વેપ પ્લેટ્સ (M754 Key Swap Stone).

## 3. થીમ અને બાયોમ્સ (Biomes)

Phase 16 સુવર્ણ ખજાના અને પ્રાચીન તિજોરીઓની ભવ્ય થીમ પર આધારિત છે:
1. **Gilded Grove (લેવલ 7501–7750):**
   - બેકગ્રાઉન્ડ પેલેટ: `#FFF8E1` (સોનેરી સૂર્યપ્રકાશ, પીળાં પાંદડાં અને પ્રાચીન ચાવીઓ).
   - વિશેષતા: M751 Key Vine અને M752 Key Crafting ના પ્રારંભિક નિયમો.
2. **Vault of Vines (લેવલ 7751–8000):**
   - બેકગ્રાઉન્ડ પેલેટ: `#FFECB3` (ઊંડો સોનેરી-કાંસ્ય રંગ, વેલાઓથી લપેટાયેલી પ્રાચીન તિજોરીઓ).
   - વિશેષતા: M753 Skeleton Key અને M754 Key Swap Stone સાથે ઉચ્ચ સ્તરની વ્યૂહાત્મક પઝલ્સ.

## 4. એન્જિન આર્કિટેક્ચર અપડેટ્સ (Key Dependency DAG Engine)

`puzzle_core` એન્જિનમાં ચાવીઓની નિર્ભરતા જાળવવા માટે ડાયરેક્ટેડ એસાયક્લિક ગ્રાફ (DAG) ઉમેરવામાં આવ્યો છે:

### 4.1 કી ઇન્વેન્ટરી અને ક્રાફ્ટિંગ મેનેજર: `KeyCraftingManager`
- ચાવીઓની સ્થિતિનું ટ્રેકિંગ:
  ```dart
  class KeyStateRecord {
    bool hasHalfKeyA;
    bool hasHalfKeyB;
    bool isCrafted => hasHalfKeyA && hasHalfKeyB;
    int skeletonKeysAvailable;
  }
  ```

### 4.2 નિર્ભરતા સાયકલ નિવારણ (Acyclic Dependency Principle)
- જનરેટર બાંહેધરી આપે છે કે ચાવીઓની શૃંખલામાં ક્યારેય સર્ક્યુલર ડેડલોક (ચાવી 1 ખોલવા માટે ચાવી 2 જોઈએ અને ચાવી 2 ખોલવા ચાવી 1 જોઈએ) શક્ય નથી.
- પ્રત્યેક સ્તરનો કી-ગ્રાફ સંપૂર્ણપણે ઉકેલી શકાય તેવો સિંગલ ડાયરેક્શનલ DAG હોય છે.

## 5. સોલ્વેબિલિટી અને શૂન્ય નુકસાન (Zero-Damage Solvability)

- તમામ 500 લેવલ્સ **0 Hearts Lost** અને **0 Boosters** સાથે ૧૦૦% સોલ્વેબલ છે.
- જો કોઈ સાપ પાસે યોગ્ય ચાવી ન હોય અને તે તાળા તરફ આગળ વધે, તો તે અથડાઈને હાર્ટ ગુમાવતો નથી; સાપ માત્ર માથું બોંક કરીને પાછો આવે છે.
- સ્વેપ સ્ટોન (M754) ટેપ કરવાથી ક્યારેય અનિવાર્ય ચાવી ગુમ થતી નથી.
