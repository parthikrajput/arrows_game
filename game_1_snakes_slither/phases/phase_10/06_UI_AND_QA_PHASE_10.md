## 1. હેડ્સ-અપ ડિસ્પ્લે (HUD) અને સ્પેશિયલ ઇન્ડિકેટર્સ

Phase 10 ના રિધમ અને સિક્વન્સિંગ ફીચર્સ માટે HUD માં નીચેના વિશિષ્ટ ઘટકો ઉમેરવામાં આવ્યા છે:

```
+-----------------------------------------------------------------------+
| [PAUSE]   LEVEL 4880 (Normal)        MOVES: 15       [COINS: 21,300] |
+-----------------------------------------------------------------------+
|  [RHYTHM: [● OPEN] [○ CLOSED]]   [TOTEM: 🔴 🟢 🔵]   [PARADE NEXT: #3] |
+-----------------------------------------------------------------------+
|                                                                       |
|                     [ FESTIVAL GAME GRID ]                            |
|             (M451 Drum Gate & M452 Totem Lock active)                 |
|                                                                       |
+-----------------------------------------------------------------------+
|  [HINT (150)]       [SHIELD (200)]       [HAMMER (250)]       [RETRY] |
+-----------------------------------------------------------------------+
```

### મુખ્ય UI ઘટકો:
1. **Rhythm Beat Ribbon:** સ્ક્રીનના ઉપરના ભાગે 2 કે 3 બીટ્સનું પ્રીવ્યૂ દર્શાવવામાં આવે છે, જેથી ખેલાડી જાણી શકે કે હવે પછીના મૂવ પર ગેટ ખુલશે કે બંધ રહેશે.
2. **Totem Pattern Indicator:** તોતેમ સ્તંભ પર જરૂરી રંગોની હારમાળા (Ribbon) દેખાય છે; જેમ જેમ સાચો સાપ નીકળે તેમ સ્લોટ ગોલ્ડન લાઈટ સાથે ટિક થાય છે.
3. **Parade Badge Callout:** પરેડ ગેટ પર આગામી કયો નંબર માન્ય છે (દા.ત. `NEXT: #2`) તેનું સ્પષ્ટ બેનર ચમકે છે.
4. **Echo Progress Bar:** Group A નો પૂર્ણ થયેલો ક્રમ ઝાંખો દેખાય છે અને Group B તેના પર ઓવરલેપ થઈને મેચ થાય છે.

## 2. વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX & SFX Mapping)

| ઇવેન્ટ / ક્રિયા | વિઝ્યુઅલ ઇફેક્ટ (VFX) | ઓડિયો પ્રભાવ (SFX) | હેપ્ટિક ફીડબેક (Haptics) |
| :--- | :--- | :--- | :--- |
| **M451 Drum Beat Cycle** | ગેટના પાયામાંથી ધ્વનિ તરંગો જેવી ગોળાકાર પલ્સ બહાર નીકળે છે (`drum_pulse_ring`). | જીવંત ટ્રાઇબલ ડ્રમ બીટ (`sfx_drum_beat.ogg`). | રિધમિક લાઇટ ટિક (Light Tap). |
| **M452 Totem Match** | રંગ સાચો મેચ થતાં તોતેમની કોતરણીમાંથી સોનેરી કિરણો ફૂટે છે (`totem_carve_glow`). | સુંદર બાંસુરી અથવા ચાઇમ સૂર (`sfx_totem_chime.wav`). | સોફ્ટ વાઇબ્રેશન (Soft Buzz). |
| **M453 Parade Step** | યોગ્ય નંબરનો સાપ બહાર નીકળતાં ઉત્સવ જેવો કલરફુલ કન્ફેટી છંટકાવ (`parade_confetti`). | ઉત્સાહભર્યો બ્યુગલ / શંખનાદ (`sfx_parade_step.wav`). | મીડિયમ ક્લિક (Medium Pulse). |
| **M454 Echo Resonance** | Group B નો સાપ સાચા ક્રમે નીકળતાં આખા બોર્ડ પર ગૂંજતી આભા (`echo_resonance_wave`). | સુરીલો ઇકો સાઉન્ડ (`sfx_echo_harp.ogg`). | ડબલ પલ્સ (Double Tap). |
| **Wrong Order Bonk** | ખોટા ક્રમે ટેપ થતાં સાપનું મોં લાલ થઈને અટકે છે (`order_bonk_shake`). | ડલ ડ્રમ થમ્પ (`sfx_drum_error.wav`). | એરર વાઇબ્રેશન (Failure Buzz). |
| **Level 5000 Halfway Finale** | 5,000 લેવલ્સ પૂર્ણ થતાં આખા આકાશમાં ભવ્ય આતશબાજી અને ગોલ્ડન સાપોનું નૃત્ય (`halfway_5000_grand_burst`). | ભવ્ય ફેસ્ટિવલ સિમ્ફની ફેનફેર (`sfx_festival_halfway.ogg`). | સળંગ સેલિબ્રેશન વાઇબ્રેશન. |

## 3. એક્સેસિબિલિટી અને કલરબ્લાઇન્ડ સપોર્ટ (Accessibility)

- **Shape & Symbol Augmented Colors:**
  - તોતેમ પેટર્ન (M452) અને ઇકો સિક્વન્સ (M454) માં માત્ર કલર પર નિર્ભરતા નથી; પ્રત્યેક રંગ સાથે ચોક્કસ ભૌમિતિક સિમ્બોલ જોડાયેલું છે:
    - લાલ = વર્તુળ (Circle ●)
    - વાદળી = ચોરસ (Square ■)
    - પીળો = ત્રિકોણ (Triangle ▲)
    - લીલો = તારો (Star ★)
- **High-Visibility Numbers:**
  - પરેડ સાપો પરના નંબરો મોટા, બોલ્ડ અને હાઇ-કોન્ટ્રાસ્ટ સફેદ બેકગ્રાઉન્ડ સાથે દર્શાવવામાં આવે છે.
- **Auditory Rhythms:**
  - ઓપન અને ક્લોઝ્ડ ગેટ્સ માટે અલગ અલગ પિચના અવાજ (High Drum vs Low Drum), જેથી દૃષ્ટિહીન ખેલાડીઓ અવાજ સાંભળીને પણ તાલ સમજી શકે.

## 4. પર્ફોર્મન્સ બજેટ્સ અને ઑપ્ટિમાઇઝેશન (Performance Budgets)

Phase 10 ના તહેવાર જેવા વાતાવરણમાં પાર્ટિકલ્સનું કડક નિયમન:

| ડિવાઇસ ટિયર (Device Tier) | મહત્તમ એકસાથે પાર્ટિકલ્સ | ટાર્ગેટ ફ્રેમરેટ (FPS) | બોર્ડ જનરેશન બજેટ | મેમરી હેડરૂમ |
| :--- | :---: | :---: | :---: | :---: |
| **Low-End Tier** (Android Go, 2GB RAM) | $\le 30$ particles | 60 FPS (min 50 FPS) | $\le 250\text{ ms}$ | $\le 90\text{ MB}$ |
| **Mid-End Tier** (4GB RAM) | $\le 80$ particles | 60 FPS | $\le 200\text{ ms}$ | $\le 110\text{ MB}$ |
| **High-End Tier** (Flagship devices) | $\le 150$ particles | 60–120 FPS | $\le 150\text{ ms}$ | $\le 130\text{ MB}$ |

- **Audio Caching:** ડ્રમ બીટ્સના ટૂંકા ઓડિયો સેમ્પલ્સ પ્રી-લોડેડ મેમરી પૂલમાં રહે છે જેથી કોઈ ઓડિયો લેટન્સી ન આવે.
- **Level Generation:** L4501–5000 નું જનરેશન $300\text{ ms}$ ની અંદર પૂર્ણ થાય છે.

## 5. ક્વોલિટી એશ્યોરન્સ ટેસ્ટિંગ ચેકલિસ્ટ (QA Checklist P10-QA-01 to P10-QA-10)

Phase 10 ના ઉત્પાદન સ્તરે પરીક્ષણ માટે નીચે મુજબના 10 ટેસ્ટ પાસ થવા અનિવાર્ય છે:

- [ ] **P10-QA-01 (M451 Move Modulo):** ડ્રમ ગેટ દરેક મૂવ પર બરાબર તેના પેટર્ન ક્રમ મુજબ ખુલે છે અને બંધ થાય છે.
- [ ] **P10-QA-02 (M451 Zero Damage):** ક્લોઝ્ડ ડ્રમ ગેટ પર અથડાતાં કોઈ હાર્ટ ન કટ થવું જોઈએ.
- [ ] **P10-QA-03 (M452 Totem History Match):** છેલ્લા $k$ સાપો બરાબર મેચ થતાં જ લોક અનલૉક થવું જોઈએ.
- [ ] **P10-QA-04 (M452 Pattern Reset):** વચ્ચે ખોટો રંગ નીકળતાં તોતેમ સાયલન્ટલી રીસેટ થવું જોઈએ પરંતુ હાર્ટ ગુમાવ્યા વિના.
- [ ] **P10-QA-05 (M453 Parade Sequence):** માત્ર લઘુત્તમ ક્રમાંકિત સાપ જ પરેડ ગેટમાંથી બહાર નીકળી શકે.
- [ ] **P10-QA-06 (M454 Echo Invariance):** Group A નો રંગ ક્રમ મેમરીમાં સંગ્રહિત રહીને Group B સાથે અક્ષરશઃ સરખાવાવો જોઈએ.
- [ ] **P10-QA-07 (Undo Integrity):** Undo કરવાથી મૂવ કાઉન્ટર પાછળ જવું જોઈએ અને ડ્રમ ગેટ પાછલા સ્ટેટ પર આવવો જોઈએ.
- [ ] **P10-QA-08 (Level 5000 Halfway Milestone):** લેવલ 5000 પૂર્ણ થતાં હાફવે સિનેમેટિક એનિમેશન અને ગ્રાન્ડ ચેસ્ટ એવોર્ડ થવી જોઈએ.
- [ ] **P10-QA-09 (Memory Leak Check):** સળંગ 50 સિક્વન્સિંગ લેવલ્સ રમીને રીસ્ટાર્ટ કરતાં મેમરી વપરાશ 120MB થી વધુ ન વધવો જોઈએ.
- [ ] **P10-QA-10 (CI Binary Verification):** `phase_10_meta.bin` ફાઇલનું સાઇઝ વેરિફિકેશન અને ચેકસમ માન્ય હોવું જોઈએ.
