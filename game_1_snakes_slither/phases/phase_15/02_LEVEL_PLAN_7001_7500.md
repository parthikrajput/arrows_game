# Phase 15: Level Plan (લેવલ 7001 થી 7500)

> આ દસ્તાવેજ **Phase 15 (Levels 7001–7500)** ના 50 બ્લોક્સ (500 લેવલ્સ) નું સ્લોટ મેપિંગ, બેઝ મિકેનિક્સ અને વેરિઅન્ટ્સ વિતરણ, હેન્ડ-ટ્યુન્ડ લેવલ્સ અને ડિફિકલ્ટી કર્વ નિર્ધારિત કરે છે.

## 1. 50 બ્લોક્સ માળખું અને સ્લોટ એલોકેશન (50-Block Architecture)

Phase 15 માં કુલ 50 બ્લોક્સ (Block 701 થી Block 750) છે. પ્રત્યેક બ્લોકમાં 10 લેવલ્સ સમાવિષ્ટ છે:

```
Block 701 (7001–7010): Signature System Intro (River Delta Conveyor Concept)
Block 702 (7011–7020): M701 Belt Junction Intro (L7011)
Block 703–713        : Variants 1 to 11
Block 714 (7131–7140): M702 Tide River Intro (L7131)
Block 715–725        : Variants 12 to 22
Block 726 (7251–7260): M703 Sluice Lever Intro (L7251)
Block 727–737        : Variants 23 to 33
Block 738 (7371–7380): M704 Whirlpool Loop Intro (L7371)
Block 739–749        : Variants 34 to 44
Block 750 (7491–7500): Review Level (L7491) + Variant 45 + Grand Finale (L7500)
```

## 4. હેન્ડ-ટ્યુન્ડ લેવલ્સની યાદી (Hand-Tuned Signature Levels)

1. **L7001 (Gentle Current):** કન્વેયર ટ્રેક પર સાપ સરકવાનો પ્રથમ સરળ અનુભવ.
2. **L7011 (M701 Tutorial):** જંક્શન સ્વીચ ટેપ કરીને સાપને ડાબે વાળવો.
3. **L7131 (M702 Tutorial):** 3-મૂવ ટાઇડ રિવર્સલ સાથે સમયબદ્ધ પઝલ.
4. **L7251 (M703 Tutorial):** સ્લૂઇસ લિવર વડે કન્વેયર બંધ કરીને સાપને પસાર થવા દેવો.
5. **L7371 (M704 Tutorial):** વમળ લૂપ: સાપ ચક્રાકારે ઘૂમે છે અને યોગ્ય સમયે ટેપ થઈને બહાર નીકળે છે.
6. **L7459 (Hard Peak):** 3 જંક્શન્સ અને 2 વમળો સાથે તીવ્ર જળપ્રવાહ ચેલેન્જ ($D = 85$).
7. **L7491 (Review Level):** તમામ 4 કન્વેયર મિકેનિક્સનું સંતુલિત રિવ્યૂ સ્તર.
8. **L7500 (Grand Finale):** 42 સાપો અને સમગ્ર ડેલ્ટા નેટવર્કમાંથી ભવ્ય એક્ઝિટ ($D = 91$).
