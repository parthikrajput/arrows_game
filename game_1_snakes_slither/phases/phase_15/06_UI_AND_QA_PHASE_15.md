## 1. હેડ્સ-અપ ડિસ્પ્લે (HUD) અને કન્વેયર ઇન્ડિકેટર્સ

Phase 15 ના કન્વેયર ટ્રેક્સ અને જંક્શન્સ માટે HUD માં નીચેના વિશિષ્ટ ઘટકો ઉમેરવામાં આવ્યા છે:

```
+-----------------------------------------------------------------------+
| [PAUSE]   LEVEL 7350 (Normal)        MOVES: 14       [COINS: 40,200] |
+-----------------------------------------------------------------------+
|  [TIDE: 🠚 EAST (FLIP IN 2 MOVES)]           [SLUICE GATE: OPEN]       |
+-----------------------------------------------------------------------+
|                                                                       |
|                      [ DELTA GAME GRID ]                              |
|           (M701 Fork Switch & M704 Whirlpool active)                  |
|                                                                       |
+-----------------------------------------------------------------------+
|  [HINT (150)]       [SHIELD (200)]       [HAMMER (250)]       [RETRY] |
+-----------------------------------------------------------------------+
```

### મુખ્ય UI ઘટકો:
1. **Tide Countdown Pill:** સ્ક્રીનના ઉપરના ભાગે કન્વેયર પ્રવાહની વર્તમાન દિશા અને હવે પછીના કેટલા મૂવ્સે ભરતી ઉલટાશે તેનો કાઉન્ટર.
2. **Dynamic Chevron Flow:** કન્વેયર ટાઇલ્સ પર સતત વહેતા તીરો (Animated Water Chevrons) જે પ્રવાહની ગતિ અને દિશા સ્પષ્ટ દર્શાવે છે.
3. **Junction Route Highlight:** M701 સ્વિચની સક્રિય શાખા પર ચમકતી લીલી લાઇન અને નિષ્ક્રિય શાખા પર લાલ ક્રોસ દેખાય છે.
4. **Whirlpool Exit Indicator:** M704 વમળ લૂપમાંથી કયા સેલ પરથી સાપ બહાર નીકળી શકે તે માટે સ્પર્શક એરો (Exit Tangent Pip) ચમકે છે.

## 2. વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX & SFX Mapping)

| ઇવેન્ટ / ક્રિયા | વિઝ્યુઅલ ઇફેક્ટ (VFX) | ઓડિયો પ્રભાવ (SFX) | હેપ્ટિક ફીડબેક (Haptics) |
| :--- | :--- | :--- | :--- |
| **M701 Junction Switch** | સ્વિચ ફરતાં જ પાણીના છાંટા અને તરંગો ઉડે છે (`junction_switch_flip`). | લાકડાના પેડલ સ્વિચનો ચપળ અવાજ (`sfx_switch_click.wav`). | શાર્પ હેપ્ટિક ક્લિક (Sharp Tap). |
| **M702 Tide Reversal** | સફેદ ફીણવાળી એક વિશાળ લહેર સમગ્ર બોર્ડ પરથી પસાર થઈને પ્રવાહ ઉલટાવે છે (`tide_reverse_surge`). | ગર્જના કરતો સમુદ્રી ભરતીનો અવાજ (`sfx_tide_surge.ogg`). | મીડિયમ પલ્સ વાઇબ્રેશન (Medium Pulse). |
| **M703 Sluice Gate Toggle** | સ્લૂઇસ ગેટ ઉંચકાતાં પાણીનું ઝડપી વહેણ શરૂ થાય છે (`sluice_water_rush`). | પ્રાચીન લાકડાના ગેટનો કચડાટ (`sfx_sluice_gate.wav`). | હેવી હેપ્ટિક ક્લિક (Heavy Tap). |
| **M704 Whirlpool Loop** | સાપ વમળમાં ઘૂમતાં તેની ફરતે વર્તુળાકાર ફીણ અને વમળ (`whirlpool_vortex_spin`). | સતત ઘૂમરાતા જળ-વમળનો ગુંજન સૂર (`sfx_whirlpool_loop.ogg`). | સતત હળવો કંપન (Soft Rattle). |
| **Conveyor Blocked Bonk** | સાપ કન્વેયર પર આગળ વધી શકતો ન હોય ત્યારે પાણીમાં અટકીને સ્થિર રહે છે (`current_stall_ripple`). | નરમ જળ-અથડામણ અવાજ (`sfx_water_stall.wav`). | એરર વાઇબ્રેશન (Failure Buzz). |
| **Level 7500 Grand Finale** | સમગ્ર ડેલ્ટા પરથી તમામ સાપો એક વિશાળ નદી સંગમમાં મુક્ત થાય છે (`delta_estuary_grand_burst`). | ભવ્ય મહાનદી સિમ્ફની ફેનફેર (`sfx_delta_finale.ogg`). | સળંગ સેલિબ્રેશન વાઇબ્રેશન. |

## 3. એક્સેસિબિલિટી અને કલરબ્લાઇન્ડ સપોર્ટ (Accessibility)

- **High-Contrast Flow Chevrons:**
  - કન્વેયર ટ્રેક પરના તીરો માત્ર રંગ પર નહીં પરંતુ 3D શેડો અને બોલ્ડ સફેદ આઉટલાઇન સાથે રેન્ડર થાય છે.
- **Directional Pip Markers:**
  - પ્રત્યેક કન્વેયર ટાઇલના ખૂણા પર નાનો અચલ દિશા-સૂચક બિંદુ હોય છે.
- **Reduce Motion Support:**
  - સતત વહેતા ચેવ્રોન એનિમેશન્સ સ્થિર (Static Arcs) બની જાય છે અને સાપો સરળ ગ્લાઇડિંગને બદલે ત્વરિત પોઝિશન શિફ્ટ કરે છે.

## 4. પર્ફોર્મન્સ બજેટ્સ અને ઑપ્ટિમાઇઝેશન (Performance Budgets)

Phase 15 ના કન્વેયર પ્રોપલ્શન અને લૂપ્સ માટે કડક ફ્રેમરેટ મર્યાદાઓ:

| ડિવાઇસ ટિયર (Device Tier) | મહત્તમ એકસાથે પાર્ટિકલ્સ | ટાર્ગેટ ફ્રેમરેટ (FPS) | બોર્ડ જનરેશન બજેટ | મેમરી હેડરૂમ |
| :--- | :---: | :---: | :---: | :---: |
| **Low-End Tier** (Android Go, 2GB RAM) | $\le 30$ particles | 60 FPS (min 50 FPS) | $\le 250\text{ ms}$ | $\le 90\text{ MB}$ |
| **Mid-End Tier** (4GB RAM) | $\le 80$ particles | 60 FPS | $\le 200\text{ ms}$ | $\le 110\text{ MB}$ |
| **High-End Tier** (Flagship devices) | $\le 150$ particles | 60–120 FPS | $\le 150\text{ ms}$ | $\le 130\text{ MB}$ |

- **Procedural Chevron Rendering:** દરેક ટાઇલ પર અલગ એનિમેશન ચલાવવાને બદલે ગ્લોબલ યુનિફોર્મ ટાઇમ પેરામીટર વડે એક જ સિંગલ પાસમાં તમામ ચેવ્રોન દોરાય છે.
- **Level Generation:** L7001–7500 નું જનરેશન $300\text{ ms}$ ની અંદર પૂર્ણ થાય છે.

## 5. ક્વોલિટી એશ્યોરન્સ ટેસ્ટિંગ ચેકલિસ્ટ (QA Checklist P15-QA-01 to P15-QA-10)

Phase 15 ના ઉત્પાદન સ્તરે પરીક્ષણ માટે નીચે મુજબના 10 ટેસ્ટ પાસ થવા અનિવાર્ય છે:

- [ ] **P15-QA-01 (M701 Switch Toggle):** જંક્શન સ્વિચ ટેપ કરતાં તે બરાબર દિશા બદલે છે અને 1 મૂવ વાપરે છે.
- [ ] **P15-QA-02 (M702 Tide Reversal Cycle):** દર નિયુક્ત $N$ મૂવ્સે ટ્રેક્સ બરાબર $180^\circ$ ઉલટાવા જોઈએ.
- [ ] **P15-QA-03 (M703 Sluice State):** સ્લૂઇસ લિવર OFF હોય ત્યારે કન્વેયર સાપને આગળ ન ધકેલવો જોઈએ.
- [ ] **P15-QA-04 (M704 Whirlpool Loop):** વમળમાં રહેલો સાપ દરેક મૂવ પર બરાબર 1 નોડ ચક્રાકારે આગળ વધવો જોઈએ.
- [ ] **P15-QA-05 (M704 Exit Tangent):** સાપનું મોં બહાર નીકળવાના પાથ પર હોય ત્યારે ટેપ કરવાથી તે સફળતાપૂર્વક લૂપ છોડવો જોઈએ.
- [ ] **P15-QA-06 (Conveyor Stall Zero Damage):** કન્વેયર પર આગળ રસ્તો બંધ હોવાથી સાપ અટકી જાય તો કોઈ હાર્ટ નષ્ટ ન થવું જોઈએ (0 Hearts Lost).
- [ ] **P15-QA-07 (Undo Conveyor State):** Undo કરવાથી સાપો અને કન્વેયર ટ્રેકની દિશાઓ અગાઉના ટર્નની સ્થિતિ પર પાછી આવવી જોઈએ.
- [ ] **P15-QA-08 (Level 7500 Finale):** લેવલ 7500 પર સમગ્ર ડેલ્ટા નેટવર્ક સફળતાપૂર્વક ક્લિયર થઈને ગ્રાન્ડ ચેસ્ટ એવોર્ડ થવી જોઈએ.
- [ ] **P15-QA-09 (Memory Leak Check):** સળંગ 50 કન્વેયર લેવલ્સ રમીને રીસ્ટાર્ટ કરતાં મેમરી વપરાશ 120MB થી વધુ ન વધવો જોઈએ.
- [ ] **P15-QA-10 (CI Binary Verification):** `phase_15_meta.bin` ફાઇલનું સાઇઝ વેરિફિકેશન અને ચેકસમ માન્ય હોવું જોઈએ.
