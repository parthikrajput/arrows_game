## 1. હેડ્સ-અપ ડિસ્પ્લે (HUD) અને સ્પેશિયલ ઇન્ડિકેટર્સ

Phase 12 ના ગુરુત્વાકર્ષણ અને પતનના ફિચર્સ માટે HUD માં નીચેના વિશિષ્ટ ઘટકો ઉમેરવામાં આવ્યા છે:

```
+-----------------------------------------------------------------------+
| [PAUSE]   LEVEL 5850 (Normal)        MOVES: 18       [COINS: 29,200] |
+-----------------------------------------------------------------------+
|  [WIND: 🠗 DOWN (GUST IN 2 MOVES)]           [FRUITS ON BOARD: 4]     |
+-----------------------------------------------------------------------+
|                                                                       |
|                     [ MONSOON GAME GRID ]                             |
|          (M551 Wind Lever & M552 Falling Fruit active)                |
|                                                                       |
+-----------------------------------------------------------------------+
|  [HINT (150)]       [SHIELD (200)]       [HAMMER (250)]       [RETRY] |
+-----------------------------------------------------------------------+
```

### મુખ્ય UI ઘટકો:
1. **Compass Wind Indicator:** સ્ક્રીનના ઉપરના ભાગે 3D પવનચક્કી એરો જે હંમેશા વર્તમાન ગુરુત્વાકર્ષણની દિશા (Down, Right, Up, Left) દર્શાવે છે.
2. **Falling Trajectory Preview:** જ્યારે ખેલાડી M551 Wind Lever પર લોંગ-પ્રેસ કરે છે, ત્યારે ફળો ક્યાં જઈને પડશે તેના ઝાંખા પતન બિંદુઓ (Ghost Drops) દેખાય છે.
3. **Heavy Python Weight Badge:** M554 અજગર પર વજનદાર પથ્થરનું પ્રતીક હોય છે જેથી ખેલાડી જાણી શકે કે આ સાપ ગુરુત્વાકર્ષણ સાથે આપોઆપ સરકશે.
4. **Floaty Lily Glow:** એન્ટી-ગ્રેવિટી ટાઇલ્સ પર ચમકતી જાંબલી આભા દેખાય છે.

## 2. વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX & SFX Mapping)

| ઇવેન્ટ / ક્રિયા | વિઝ્યુઅલ ઇફેક્ટ (VFX) | ઓડિયો પ્રભાવ (SFX) | હેપ્ટિક ફીડબેક (Haptics) |
| :--- | :--- | :--- | :--- |
| **M551 Lever Rotation** | સમગ્ર બોર્ડ પરથી વરસાદી પવનના સુસવાટાની લહેર પસાર થાય છે (`gravity_shift_wind`). | લાકડાના યાંત્રિક ગિયરનો અવાજ (`sfx_lever_ratchet.wav`). | શાર્પ હેપ્ટિક ક્લિક (Sharp Click). |
| **M552 Fruit Drop** | ફળ ઝડપથી નીચે પડીને જમીન સાથે અથડાતાં ધૂળ અને પાંદડાં ઉડે છે (`fruit_impact_dust`). | ભારે નાળિયેર પછડાવાનો અવાજ (`sfx_fruit_thud.wav`). | સોલિડ બોંક ફીડબેક (Medium Pulse). |
| **M553 Floaty Lily Hold** | ફળ લીલી પર રોકાતાં જ તેની આસપાસ ગુરુત્વાકર્ષણ પ્રતિકારક સ્પાર્કલ્સ (`anti_grav_float_shimmer`). | રહસ્યમય ગુંજન સૂર (`sfx_lily_hum.ogg`). | સૂક્ષ્મ વાઇબ્રેશન (Light Tap). |
| **M554 Heavy Python Slide** | ભારે અજગર નીચે સરકતાં સ્ક્રીન પર હળવો આંચકો (`ground_shake_slide`). | જમીન પર ઘસડાવાનો ઊંડો અવાજ (`sfx_heavy_python_scrape.wav`). | ભારે ડબલ વાઇબ્રેશન (Heavy Rattle). |
| **Fruit Stops on Snake** | ફળ સાપના શરીર પર અટકી જતાં સાપ સામાન્ય બ્લિંક કરે છે (`snake_cushion_ripple`). | નરમ કુશનિંગ અવાજ (`sfx_soft_thud.wav`). | સોફ્ટ પલ્સ (Soft Buzz). |
| **Level 6000 Grand Finale** | સંપૂર્ણ બોર્ડ પર વાવાઝોડું, વીજળી અને સોનેરી ફળોનો ભવ્ય વરસાદ (`monsoon_hurricane_burst`). | વિજયી મોન્સૂન સિમ્ફની ફેનફેર (`sfx_monsoon_finale.ogg`). | સળંગ સેલિબ્રેશન વાઇબ્રેશન. |

## 3. એક્સેસિબિલિટી અને કલરબ્લાઇન્ડ સપોર્ટ (Accessibility)

- **Vector Direction Arrows on Obstacles:**
  - ફળો અને ભારે સાપો પર દિશા દર્શાવતા નાના તીરો (Arrows) પણ અંકિત છે, જેથી માત્ર HUD એરો પર જ નિર્ભર રહેવું ન પડે.
- **High Contrast Wind Vane:**
  - પવનચક્કી સૂચક બોલ્ડ રંગો અને સફેદ આઉટલાઇન સાથે રેન્ડર થાય છે.
- **Reduce Motion Support:**
  - કેમેરા શેક અને તીવ્ર પવનના એનિમેશન્સ બંધ થઈ જાય છે; ફળો સીધા તેમના નવા સેલમાં ટેલિપોર્ટ થઈને સ્થિર થાય છે.

## 4. પર્ફોર્મન્સ બજેટ્સ અને ઑપ્ટિમાઇઝેશન (Performance Budgets)

Phase 12 માં પડતા ફળોના ભૌતિકશાસ્ત્ર માટે કડક ફ્રેમરેટ મર્યાદાઓ:

| ડિવાઇસ ટિયર (Device Tier) | મહત્તમ એકસાથે પાર્ટિકલ્સ | ટાર્ગેટ ફ્રેમરેટ (FPS) | બોર્ડ જનરેશન બજેટ | મેમરી હેડરૂમ |
| :--- | :---: | :---: | :---: | :---: |
| **Low-End Tier** (Android Go, 2GB RAM) | $\le 30$ particles | 60 FPS (min 50 FPS) | $\le 250\text{ ms}$ | $\le 90\text{ MB}$ |
| **Mid-End Tier** (4GB RAM) | $\le 80$ particles | 60 FPS | $\le 200\text{ ms}$ | $\le 110\text{ MB}$ |
| **High-End Tier** (Flagship devices) | $\le 150$ particles | 60–120 FPS | $\le 150\text{ ms}$ | $\le 130\text{ MB}$ |

- **Physics Settling Optimization:** સેટલિંગ લૂપ વધુમાં વધુ $\text{GridSize}$ ટર્ન્સમાં સમાપ્ત થઈ જાય છે.
- **Level Generation:** L5501–6000 નું જનરેશન $300\text{ ms}$ ની અંદર પૂર્ણ થાય છે.

## 5. ક્વોલિટી એશ્યોરન્સ ટેસ્ટિંગ ચેકલિસ્ટ (QA Checklist P12-QA-01 to P12-QA-10)

Phase 12 ના ઉત્પાદન સ્તરે પરીક્ષણ માટે નીચે મુજબના 10 ટેસ્ટ પાસ થવા અનિવાર્ય છે:

- [ ] **P12-QA-01 (M551 90-Deg Rotation):** લિવર ટેપ કરવાથી ગુરુત્વાકર્ષણ બરાબર $90^\circ$ ક્લોકવાઇઝ ફરે છે અને 1 મૂવ વપરાય છે.
- [ ] **P12-QA-02 (M552 Falling Bounds):** ફળ ક્યારેય ગ્રીડની બહાર ન પડવું જોઈએ અને દીવાલ સાથે યોગ્ય રીતે અથડાઈને અટકવું જોઈએ.
- [ ] **P12-QA-03 (M552 Snake Preservation):** ફળ નીચે ઊભેલા સાપના શરીર પર અટકે છે અને સાપને કોઈ નુકસાન (0 Heart Loss) થતું નથી.
- [ ] **P12-QA-04 (M553 Anti-Grav Tile):** એન્ટી-ગ્રેવિટી ટાઇલ પરનું ફળ કોઈપણ દિશાના ગુરુત્વાકર્ષણમાં નીચે ન પડવું જોઈએ.
- [ ] **P12-QA-05 (M554 Python Slide):** ભારે સાપ પોતાની નીચેની તમામ ટાઇલ્સ ખાલી હોય ત્યારે જ ગુરુત્વાકર્ષણમાં 1 સેલ સરકવો જોઈએ.
- [ ] **P12-QA-06 (Deadlock Prevention):** ફળો પડ્યા પછી ક્યારેય તમામ એક્ઝિટ લેન એકસાથે બ્લોક ન થવી જોઈએ.
- [ ] **P12-QA-07 (Undo Physics Equilibrium):** Undo કરવાથી ગુરુત્વાકર્ષણ અને તમામ પડેલા ફળો અગાઉની સ્થિતિ પર પુનઃસ્થાપિત થવા જોઈએ.
- [ ] **P12-QA-08 (Level 6000 Finale):** લેવલ 6000 પર વાવાઝોડા વચ્ચે તમામ સાપો મુક્ત થઈને ગ્રાન્ડ ચેસ્ટ એવોર્ડ થવી જોઈએ.
- [ ] **P12-QA-09 (Memory Leak Check):** સળંગ 50 ગ્રેવિટી લેવલ્સ રમીને રીસ્ટાર્ટ કરતાં મેમરી વપરાશ 120MB થી વધુ ન વધવો જોઈએ.
- [ ] **P12-QA-10 (CI Binary Verification):** `phase_12_meta.bin` ફાઇલનું સાઇઝ વેરિફિકેશન અને ચેકસમ માન્ય હોવું જોઈએ.
