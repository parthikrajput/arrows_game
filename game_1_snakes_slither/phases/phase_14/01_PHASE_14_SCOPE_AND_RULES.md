# Phase 14: Scope and Rules (લેવલ 6501 થી 7000)

> આ દસ્તાવેજ **Phase 14 (Pond Reflections: Mirror Worlds)** નું કાર્યક્ષેત્ર, એન્જિન નિયમો, દ્વિપક્ષીય સપ્રમાણતા (Bilateral Symmetry), ગ્રીડ મર્યાદાઓ અને ડિફિકલ્ટી બેન્ડ નિર્ધારિત કરે છે.

**Related docs:** [Phase 14 Index](./README.md) · [Shared Core Standard §11, §12](../../SHARED_CORE_STANDARD.md) · [Scaling to 10,000 §2–§6](../../SCALING_TO_10000_LEVELS.md)

---

## 1. ક્ષેત્ર અને હેતુ (Scope & Objective)
Phase 14 માં ખેલાડીઓ શાંત જળની સપાટી પર રચાતા પ્રતિબિંબિત વિશ્વ (Mirror Worlds) માં પ્રવેશ કરે છે. આ ફેઝમાં બોર્ડના કેન્દ્રમાંથી એક જળ-અક્ષ (Pond Axis) પસાર થાય છે:
- અક્ષની બંને બાજુના સાપો સપ્રમાણ રીતે એકસાથે ચાલે છે (M651 Pond Axis).
- વિરુદ્ધ કિનારાનો કી-સાપ બહાર નીકળતાં આ બાજુના તાળા ખુલે છે (M652 Reflection Lock).
- બે જોડિયાં બોર્ડ્સ જે સમાન ટેપ ક્રમ માંગે છે (M653 Twin Board).
- ઊંધો સાપ જે મિરર સાથી કરતાં વિરુદ્ધ દિશામાં ચાલે છે (M654 Upside-down Snake).

## 3. થીમ અને બાયોમ્સ (Biomes)

Phase 14 સ્ફટિક જેવા કાચ જેવા પાણી અને પ્રતિબિંબોની સુંદરતા પર આધારિત છે:
1. **Crystal Pool (લેવલ 6501–6750):**
   - બેકગ્રાઉન્ડ પેલેટ: `#E1F5FE` (સ્વચ્છ સ્ફટિકીય વાદળી પાણી, સૂર્યના કિરણોનું પ્રતિબિંબ).
   - વિશેષતા: M651 Pond Axis અને M652 Reflection Lock નો પરિચય.
2. **Obsidian Reflection (લેવલ 6751–7000):**
   - બેકગ્રાઉન્ડ પેલેટ: `#B3E5FC` (ઘેરા વાદળી અને ઓબ્સિડિયન પથ્થરોના જળાશયો).
   - વિશેષતા: M653 Twin Board અને M654 Upside-down Snake સાથે ઉચ્ચ સ્તરની જટિલ સપ્રમાણ પઝલ્સ.

## 4. એન્જિન આર્કિટેક્ચર અપડેટ્સ (Mirror World Engine State)

`puzzle_core` એન્જિનમાં સપ્રમાણતા માટે નીચે મુજબના ડેટા મોડેલ્સ ઉમેરવામાં આવ્યા છે:

### 4.1 મિરર પેરિંગ રજિસ્ટ્રી: `MirrorPairRegistry`
- પ્રત્યેક સાપ પોતાની મિરર આઈડી સાથે જોડાયેલો હોય છે:
  ```dart
  class MirrorSnakePair {
    final int snakeA_Id;
    final int snakeB_Id;
    final MirrorAxisType axis; // horizontal or vertical
    final bool isInverse;      // true for M654 Upside-down Snake
  }
  ```
- જ્યારે સાપ A પર ટેપ થાય છે, ત્યારે એન્જિન સાપ B માટે આપોઆપ મુવમેન્ટ વેક્ટર ગણે છે:
  - સમાંતર સાપ: $\vec{V}_B = \text{Reflect}(\vec{V}_A, \text{Axis})$.
  - ઇન્વર્સ સાપ (M654): $\vec{V}_B = -\text{Reflect}(\vec{V}_A, \text{Axis})$.

### 4.2 સિંક્રનાઇઝ્ડ સેફ્ટી કન્સ્ટ્રેઇન્ટ (Synchronous Safety §16.4)
- જો બેમાંથી કોઈપણ એક સાપનો પાથ બંધ હોય:
  - બંને સાપ આગળ વધતા નથી.
  - બંને એકસાથે માથું બોંક કરીને પાછા વળે છે.
  - ખેલાડીનું **0 Hearts** નુકસાન થાય છે (Zero Damage Standard).

## 5. સોલ્વેબિલિટી અને શૂન્ય નુકસાન (Zero-Damage Solvability)

- તમામ 500 લેવલ્સ **0 Hearts Lost** અને **0 Boosters** સાથે ૧૦૦% સોલ્વેબલ છે.
- જનરેટર ખાતરી કરે છે કે વિરુદ્ધ કિનારાનું લોક (M652) ખુલવા માટે જરૂરી કી-સાપ ક્યારેય ડેડલોકમાં ફસાયેલો ન હોય.
- સપ્રમાણતા છતાં પઝલ એકતરફી મુશ્કેલ ન બને તેની A* સોલ્વર દ્વારા ચકાસણી થાય છે.
