## 1. હેડ્સ-અપ ડિસ્પ્લે (HUD) અને સેન્ટ્રલ અક્ષ સિસ્ટમ

Phase 14 ના પ્રતિબિંબિત વિશ્વ માટે HUD અને બોર્ડ વિભાજક નીચે મુજબ ડિઝાઇન કરવામાં આવ્યા છે:

```
+-----------------------------------------------------------------------+
| [PAUSE]   LEVEL 6850 (Normal)        MOVES: 20       [COINS: 36,400] |
+-----------------------------------------------------------------------+
|  [MIRROR AXIS: VERTICAL]             [REFLECT LOCK: KEY IN TRANSIT]   |
+-----------------------------------------------------------------------+
|                                                                       |
|        [ SIDE A: LEFT POND ]     ~ | ~     [ SIDE B: RIGHT POND ]     |
|         (Snake A1, Snake A2)     ~ | ~      (Snake B1, Inverse B2)    |
|                                  ~ | ~                                |
|                                                                       |
+-----------------------------------------------------------------------+
|  [HINT (150)]       [SHIELD (200)]       [HAMMER (250)]       [RETRY] |
+-----------------------------------------------------------------------+
```

### મુખ્ય UI ઘટકો:
1. **Caustic Water Axis Line:** બોર્ડના કેન્દ્રમાં કાચ જેવા પાણીની ચમકતી લાઇન જે બંને બાજુ વચ્ચે સપ્રમાણતા જાળવે છે.
2. **Mirror Link Aura:** જ્યારે ખેલાડી સાપ પર ટેપ કે લોંગ-પ્રેસ કરે છે, ત્યારે અક્ષની સામેની બાજુ રહેલા તેના મિરર જોડીદાર સાપ પર સમાન રંગની પલ્સિંગ આભા દેખાય છે.
3. **Inverse Direction Glyph:** M654 ઊંધા સાપના માથા પર વિરુદ્ધ દિશા દર્શાવતું લાલ-પીળું એરો પ્રતીક હોય છે જેથી ખેલાડી જાણી શકે કે તે ઉલટી દિશામાં સરકશે.
4. **Cross-Axis Ripple Beam:** જ્યારે કી-સાપ નીકળે છે, ત્યારે પાણીની એક સુંદર લહેર અક્ષ પાર કરીને લક્ષિત દરવાજાને અડે છે.

## 2. વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX & SFX Mapping)

| ઇવેન્ટ / ક્રિયા | વિઝ્યુઅલ ઇફેક્ટ (VFX) | ઓડિયો પ્રભાવ (SFX) | હેપ્ટિક ફીડબેક (Haptics) |
| :--- | :--- | :--- | :--- |
| **M651 Mirror Slither** | બંને સાપ સમાંતર સરકે ત્યારે બંનેના રસ્તા પર સ્ફટિક જેવા કણો (`mirror_crystal_sparkle`). | હાર્મોનિક ડબલ ચાઇમ સાઉન્ડ (`sfx_mirror_slither.ogg`). | સંતુલિત ડબલ વાઇબ્રેશન (Double Pulse). |
| **M652 Reflection Unlock** | જળ-તરંગ અક્ષ પાર કરીને ગેટ પર સ્પાર્કલ્સ સાથે અથડાય છે (`water_ripple_wave`). | સુરીલો ક્રિસ્ટલ બેલ અવાજ (`sfx_reflect_unlock.wav`). | લાઇટ ક્લિક (Light Tap). |
| **M653 Twin Board Clear** | બંને બોર્ડ પર એકસાથે સાપો મુક્ત થતાં ગોલ્ડન સ્પ્લેશ (`twin_board_splash`). | ભવ્ય વોટર સિમ્ફની સૂર (`sfx_twin_clear.ogg`). | મીડિયમ પલ્સ (Medium Buzz). |
| **M654 Inverse Slither** | ઊંધો સાપ વિરુદ્ધ દિશામાં સરકતાં પાછળ જાંબલી ધુમાડો (`inverse_motion_smoke`). | ઊંડો રિવર્સ વ્હૂશ અવાજ (`sfx_inverse_swoosh.wav`). | તીવ્ર શોર્ટ વાઇબ્રેશન (Sharp Tap). |
| **Axis Collision Bonk** | બેમાંથી એક સાપ બ્લોક થતાં બંને એકસાથે પાણીમાં અટકે છે (`axis_ripple_bonk`). | પાણી પર થપ્પડ પછડાવાનો અવાજ (`sfx_pond_bonk.wav`). | એરર વાઇબ્રેશન (Failure Buzz). |
| **Level 7000 Grand Finale** | સમગ્ર બોર્ડ પર ઓબ્સિડિયન ક્રિસ્ટલ્સનું ભવ્ય વિસ્ફોટક પરાવર્તન (`obsidian_shimmer_burst`). | વિજયી મિરર ફેનફેર ઓર્કેસ્ટ્રા (`sfx_mirror_finale.ogg`). | સળંગ સેલિબ્રેશન વાઇબ્રેશન. |

## 3. એક્સેસિબિલિટી અને કલરબ્લાઇન્ડ સપોર્ટ (Accessibility)

- **Pair-Matching Shape Badges:**
  - મિરર સાપોની જોડી પર માત્ર રંગ આધારિત જોડાણ નથી; બંને સાપો પર સમાન જ ભૌમિતિક સિમ્બોલ (દા.ત. ડાયમંડ $\diamond$, હેક્સાગોન $\hexagon$) અંકિત થયેલું હોય છે.
- **High-Contrast Divider Line:**
  - જળ-અક્ષ રેખા 2px ની ઘેરી વાદળી અને સફેદ બોર્ડર સાથે સ્પષ્ટ દેખાય છે.
- **Inverse Motion Indicator:**
  - M654 ના શરીર પર વિરુદ્ધ દિશા દર્શાવતી પટ્ટીઓ (Stripes) ઊંધી દિશામાં એનિમેટ થાય છે જેથી ગતિ સ્પષ્ટ જણાય.

## 4. પર્ફોર્મન્સ બજેટ્સ અને ઑપ્ટિમાઇઝેશન (Performance Budgets)

Phase 14 ના પ્રતિબિંબિત શેડર્સ અને દ્વિપક્ષીય એનિમેશન માટે કડક મર્યાદાઓ:

| ડિવાઇસ ટિયર (Device Tier) | મહત્તમ એકસાથે પાર્ટિકલ્સ | ટાર્ગેટ ફ્રેમરેટ (FPS) | બોર્ડ જનરેશન બજેટ | મેમરી હેડરૂમ |
| :--- | :---: | :---: | :---: | :---: |
| **Low-End Tier** (Android Go, 2GB RAM) | $\le 30$ particles | 60 FPS (min 50 FPS) | $\le 250\text{ ms}$ | $\le 90\text{ MB}$ |
| **Mid-End Tier** (4GB RAM) | $\le 80$ particles | 60 FPS | $\le 200\text{ ms}$ | $\le 110\text{ MB}$ |
| **High-End Tier** (Flagship devices) | $\le 150$ particles | 60–120 FPS | $\le 150\text{ ms}$ | $\le 130\text{ MB}$ |

- **Mirror Shader Fallback:** લો-એન્ડ ડિવાઇસ પર ગણતરીયુક્ત રિફ્લેક્શન શેડરને બદલે કેનવાસ મિરરિંગ ટ્રાન્સફોર્મ (`canvas.scale(-1, 1)`) નો ઉપયોગ થાય છે.
- **Level Generation:** L6501–7000 નું જનરેશન $300\text{ ms}$ ની અંદર પૂર્ણ થાય છે.

## 5. ક્વોલિટી એશ્યોરન્સ ટેસ્ટિંગ ચેકલિસ્ટ (QA Checklist P14-QA-01 to P14-QA-10)

Phase 14 ના ઉત્પાદન સ્તરે પરીક્ષણ માટે નીચે મુજબના 10 ટેસ્ટ પાસ થવા અનિવાર્ય છે:

- [ ] **P14-QA-01 (M651 Symmetrical Mirroring):** સાપ A ટેપ કરતાં સાપ B બરાબર તેની સપ્રમાણ દિશામાં આગળ વધવો જોઈએ.
- [ ] **P14-QA-02 (M651 Dual Blockage Safety):** બેમાંથી એક પણ સાપ બ્લોક હોય તો બંને સાપ 0 હાર્ટ નુકસાન સાથે અટકવા જોઈએ.
- [ ] **P14-QA-03 (M652 Cross-Axis Unlock):** વિરુદ્ધ કિનારાનો કી-સાપ સંપૂર્ણ બહાર નીકળે ત્યારે જ દરવાજો અનલૉક થવો જોઈએ.
- [ ] **P14-QA-04 (M653 Twin Board Match):** બંને બોર્ડના સાપો પોતાની નિર્ધારિત જોડી સાથે સંપૂર્ણ સુમેળમાં રહેવા જોઈએ.
- [ ] **P14-QA-05 (M654 Inverse Motion):** ઊંધો સાપ પોતાના સાથીદારની તદ્દન વિરુદ્ધ દિશામાં જ સરકવો જોઈએ.
- [ ] **P14-QA-06 (Deadlock Prevention):** અક્ષની બંને બાજુના સાપો ક્યારેય એકબીજાને ડેડલોકમાં ન ફસાવવા જોઈએ.
- [ ] **P14-QA-07 (Undo Mirror Integrity):** Undo કરવાથી બંને બાજુના સાપો પોતાની પૂર્વ સ્થિતિ પર પુનઃસ્થાપિત થવા જોઈએ.
- [ ] **P14-QA-08 (Level 7000 Finale):** લેવલ 7000 પર ઓબ્સિડિયન મિરર પઝલ સફળતાપૂર્વક ક્લિયર થઈને ગ્રાન્ડ ચેસ્ટ એવોર્ડ થવી જોઈએ.
- [ ] **P14-QA-09 (Memory Leak Check):** સળંગ 50 મિરર લેવલ્સ રમીને રીસ્ટાર્ટ કરતાં મેમરી વપરાશ 120MB થી વધુ ન વધવો જોઈએ.
- [ ] **P14-QA-10 (CI Binary Verification):** `phase_14_meta.bin` ફાઇલનું સાઇઝ વેરિફિકેશન અને ચેકસમ માન્ય હોવું જોઈએ.
