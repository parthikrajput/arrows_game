# Phase 9: Level Plan (લેવલ 4001 થી 4500)

> આ દસ્તાવેજ **Phase 9 (Levels 4001–4500)** ના 50 બ્લોક્સ (500 લેવલ્સ) નું સંપૂર્ણ સ્લોટ મેપિંગ, બેઝ મિકેનિક્સ અને વેરિઅન્ટ્સનું વિતરણ, હેન્ડ-ટ્યુન્ડ લેવલ્સ અને ડિફિકલ્ટી કર્વ નિર્ધારિત કરે છે.

## 1. 50 બ્લોક્સ માળખું અને સ્લોટ એલોકેશન (50-Block Architecture)

Phase 9 માં કુલ 50 બ્લોક્સ (Block 401 થી Block 450) છે. પ્રત્યેક બ્લોકમાં 10 લેવલ્સ સમાવિષ્ટ છે:

```
Block 401 (4001–4010): Signature System Intro (Twin Rivers Concept)
Block 402 (4011–4020): M401 Merger Pad Intro (L4011)
Block 403–413        : Variants 1 to 11
Block 414 (4131–4140): M402 Twin Splitter Intro (L4131)
Block 415–425        : Variants 12 to 22
Block 426 (4251–4260): M403 Bead Lock Intro (L4251)
Block 427–437        : Variants 23 to 33
Block 438 (4371–4380): M404 Reunion Gate Intro (L4371)
Block 439–449        : Variants 34 to 44
Block 450 (4491–4500): Review Level (L4491) + Variant 45 + Grand Finale (L4500)
```

## 2. 10-લેવલ સ્લોટ પેટર્ન (Standard 10-Level Block Template)

દરેક 10-લેવલના બ્લોકમાં કઠિનતા અને ઉદ્દેશ્યનું ચોક્કસ વિતરણ નીચે મુજબ રહે છે:

| સ્લોટ (Slot) | પેટર્ન / પ્રકાર | ડિફિકલ્ટી બેન્ડ (D) | વર્ણન |
| :---: | :--- | :---: | :--- |
| **x1** | **Feature / Mechanic Slot** | 60–64 | નવું મિકેનિક, વેરિઅન્ટ અથવા સિગ્નેચર ફીચર રજૂ થાય છે |
| **x2** | Standard Easy | 60–62 | નવા મિકેનિકની સરળ સમજૂતી અને પ્રેક્ટિસ |
| **x3** | Standard Normal | 63–66 | મિકેનિક સાથે 1 જૂનું ઓબ્સ્ટેકલ જોડાય છે |
| **x4** | Easy Breather | 61–63 | હળવું સ્તર, ઝડપી ગતિથી ઉકેલાય |
| **x5** | Standard Normal | 65–68 | બે થી ત્રણ સાપોના જટિલ પાથિંગ |
| **x6** | Mid Normal | 67–70 | મધ્યમ જટિલતા, ટાઇટ સ્પેસ ટર્ન્સ |
| **x7** | Upper Normal | 69–72 | મલ્ટીપલ સેગમેન્ટ ટ્રાન્સફોર્મેશન |
| **x8** | High Normal | 72–75 | સંપૂર્ણ બોર્ડ કોઓર્ડિનેશન |
| **x9** | **Hard Level** | **82–85** | બ્લોકનું સૌથી કઠિન સ્તર, ચોક્કસ ક્રમ અનિવાર્ય |
| **x0** | **Milestone Gate** | 70–74 | ગિફ્ટ બાસ્કેટ અનલૉક લેવલ (300 કોઈન્સ + બૂસ્ટર) |

## 4. હેન્ડ-ટ્યુન્ડ લેવલ્સની યાદી (Hand-Tuned Signature Levels)

ઓન-ડિવાઇસ એલ્ગોરિધમિક જનરેશન છતાં, નીચેના મહત્વપૂર્ણ લેવલ્સ ક્યુરેટેડ અને ખાસ હેન્ડ-ટ્યુન્ડ રાખવામાં આવ્યા છે:
1. **L4001 (Signature Hook):** 2 સરળ સાપ પેડ પર મળે છે અને મર્જ થઈને બહાર નીકળે છે.
2. **L4011 (M401 Tutorial):** મર્જર પેડનું પ્રથમ સ્ટેપ-બાય-સ્ટેપ ઇન્ટરેક્ટિવ ગાઇડ.
3. **L4131 (M402 Tutorial):** સ્પ્લિટિંગ પાથનો પરિચય; બંને બહાર નીકળવાના પાથ ખુલ્લા રાખવાનું પ્રદર્શન.
4. **L4251 (M403 Tutorial):** સેગમેન્ટ કાઉન્ટર લોક (5 સેગમેન્ટ બહાર નીકળતાં લોક ખુલે).
5. **L4371 (M404 Tutorial):** બે અર્ધભાગ સાપ સફળતાપૂર્વક બહાર નીકળીને દરવાજો અનલૉક કરે છે.
6. **L4459 (Hard Peak):** 3 સ્પ્લિટર્સ અને 2 મર્જર પેડ્સ સાથે અત્યંત જટિલ પઝલ ($D = 85$).
7. **L4491 (Review Level):** કોઈ નવું તત્વ નહીં, તમામ 4 મિકેનિક્સનું નિર્દોષ મિશ્રણ.
8. **L4500 (Grand Finale):** 42 સાપો અને મલ્ટી-સ્ટેજ મર્જર/સ્પ્લિટિંગ સાથે ભવ્ય ચેલેન્જ ($D = 91$).
