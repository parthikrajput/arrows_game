## 1. સિગ્નેચર સિસ્ટમ: ટ્વિન રિવર્સ (Twin Rivers: Split & Merge)

Twin Rivers એ સાપના મૂળભૂત આકાર અને ઓળખમાં થતા પરિવર્તનનું મિકેનિઝમ છે. આ પઝલ સિસ્ટમમાં સાપ માત્ર બોર્ડ પરથી સરકતા નથી, પરંતુ પરિસ્થિતિ મુજબ એકબીજા સાથે જોડાઈ શકે છે અથવા બે જુદા જુદા રસ્તાઓમાં વિભાજીત થઈ શકે છે.

```
       [SNAKE A] ---> \
                       [M401 MERGER PAD] ---> [MERGED LONG SNAKE A+B]
       [SNAKE B] ---> /

                       /---> [SNAKE A_LEFT]  (90° Left)
       [SNAKE] ------> [M402 TWIN SPLITTER]
                       \---> [SNAKE A_RIGHT] (90° Right)
```

## 2. 4 નવા બેઝ મિકેનિક્સ (The 4 Base Mechanics)

### 2.1 M401: Hug Pad / Merger Pad (મર્જર પેડ)
- **પ્રથમ પરિચય:** Level 4011 (Block 402, x1 slot).
- **કાર્યપદ્ધતિ:**
  - બોર્ડ પર 2 અડીને આવેલા સેલ પર એક વિશિષ્ટ "Hug Pad" અંકિત થયેલ હોય છે.
  - જ્યારે બે જુદા જુદા સાપોના મોં (Heads) આ બે પડોશી પેડ સેલ પર આવીને સ્થિર થાય છે, ત્યારે તે પેડ પ્રકાશિત થાય છે.
  - ખેલાડી પેડ પર ટેપ કરે છે ત્યારે બંને સાપ એક સિંગલ સાપ તરીકે જોડાઈ જાય છે:
    $$\text{Merged Snake} = \text{Head}_A + \text{Body}_A + \text{Body}_B$$
  - મર્જ થયેલો નવો સાપ સાપ A ની મૂળ દિશામાં આગળ વધે છે.
- **એજ કેસ (Edge Cases):**
  - જો મર્જ થયા પછીનો આગળનો પાથ બ્લોક હોય, તો પેડ ટેપ કરવા છતાં સાપ મર્જ થઈને અથડાશે નહીં; તે રસ્તો ખુલવાની પ્રતીક્ષા કરશે.
  - સાપ B નું મૂળ હેડ બોડી સેગમેન્ટમાં રૂપાંતરિત થઈ જાય છે.

---

### 2.2 M402: Fork Stump / Twin Splitter (ટ્વિન સ્પ્લિટિંગ સ્ટમ્પ)
- **પ્રથમ પરિચય:** Level 4131 (Block 414, x1 slot).
- **કાર્યપદ્ધતિ:**
  - જ્યારે કોઈ સાપ આ વિશેષ કાંટાવાળી ટાઇલ (Fork Stump) પરથી આગળ વધે છે, ત્યારે તે સાપ બે સમાન અર્ધભાગોમાં વહેંચાઈ જાય છે.
  - ડાબી બાજુનો અર્ધભાગ $90^\circ$ ડાબે વળે છે, અને જમણી બાજુનો અર્ધભાગ $90^\circ$ જમણે વળે છે.
  - **વિભાજન સૂત્ર (Odd Segments):**
    - જો સાપના કુલ સેગમેન્ટ્સ $N = 5$ હોય, તો લીડિંગ હેડ સાપને $\lceil 5/2 \rceil = 3$ સેગમેન્ટ્સ મળશે, અને બીજા અર્ધભાગને $\lfloor 5/2 \rfloor = 2$ સેગમેન્ટ્સ મળશે અને તેને નવું હેડ પ્રાપ્ત થશે.
- **ક્રિટિકલ રૂલ (Zero Damage Gate):**
  - સ્પ્લિટ થવા માટે ડાબો અને જમણો **બંને પાથ એકસાથે ખાલી** હોવા અનિવાર્ય છે. જો બેમાંથી એક પણ પાથ બંધ હોય, તો સાપ સ્ટમ્પ સાથે બોંક થઈને અટકી જશે અને 0 Hearts ગુમાવશે.

---

### 2.3 M403: Bead Lock / Segment Lock (સેગમેન્ટ બીડ લોક)
- **પ્રથમ પરિચય:** Level 4251 (Block 426, x1 slot).
- **કાર્યપદ્ધતિ:**
  - એક દરવાજો અથવા અવરોધક પથ્થર જેના પર ગણતરી માટેના બીડ્સ (મણકાઓ) અંકિત હોય છે.
  - આ લોક સાપોની સંખ્યા પર નહીં, પરંતુ બોર્ડમાંથી બહાર નીકળેલા **કુલ સેગમેન્ટ્સ (શરીરના કટકા)** ની સંખ્યા પર આધાર રાખે છે.
  - દા.ત. $N = 12$ સેગમેન્ટ્સની જરૂર હોય, તો 4 સેગમેન્ટ્સવાળા 3 સાપ અથવા 6 સેગમેન્ટ્સવાળા 2 સાપ બહાર નીકળતાં જ લોક કાયમી ધોરણે ખુલી જાય છે.

---

### 2.4 M404: Reunion Gate / Rejoin Gate (રિયુનિયન ગેટ)
- **પ્રથમ પરિચય:** Level 4371 (Block 438, x1 slot).
- **કાર્યપદ્ધતિ:**
  - આ દરવાજો ચોક્કસ M402 Splitter દ્વારા વિભાજીત થયેલી સાપની જોડી સાથે લિંક થયેલો હોય છે.
  - દરવાજા પર વિભાજીત સાપની જોડીનું પ્રતીક હોય છે.
  - જ્યાં સુધી વિભાજીત થયેલા **બંને અર્ધભાગ સાપ સફળતાપૂર્વક બોર્ડમાંથી બહાર ન નીકળે**, ત્યાં સુધી દરવાજો ખુલતો નથી.
  - બંને ભાગ બહાર નીકળતાં જ દરવાજો અનલૉક થઈને પાછળ રહેલા અન્ય સાપો માટે રસ્તો સાફ કરે છે.

## 3. એન્જિન ટિક ઓર્ડર (Engine Tick Sequence §16.17)

પ્રત્યેક મૂવ દરમિયાન નીચે મુજબના ક્રમમાં સ્ટેટ્સ અપડેટ થાય છે:

```
Step 1: Player Tap Input -> Active Snake Selection
Step 2: Path Clearance Evaluation (Ahead, Fork-Left, Fork-Right)
Step 3: Movement Execution:
        - If entering M401 (Merger Pad): Merge entities & re-index body segments.
        - If entering M402 (Twin Splitter): Spawn child snake entity & branch paths.
Step 4: Exit Lane Detection:
        - Segments exiting board -> Add to M403 Bead Counter.
        - Split-child exiting board -> Mark M404 Reunion checklist.
Step 5: Lock Updates:
        - If M403 counter >= Target -> Retract Segment Lock.
        - If M404 both halves exited -> Open Reunion Gate.
Step 6: Board Settled -> Ready for Next Turn.
```

## 4. એલ્ગોરિધમિક સોલ્વેબિલિટી ગેરંટી (Solver Rules)

1. **Deadlock Prevention:** જનરેટર ખાતરી કરે છે કે સ્પ્લિટ થયેલા સાપો એકબીજાના એક્ઝિટ પાથને ક્યારેય પરસ્પર બ્લોક ન કરે.
2. **Segment Balance:** બોર્ડ પર ઉપલબ્ધ સાપોના કુલ સેગમેન્ટ્સ હંમેશા તમામ M403 Bead Locks ની જરૂરિયાત કરતાં સમાન અથવા વધુ હોવા જોઈએ.
3. **Reversible Simulation:** A* સોલ્વર સ્પ્લિટ થયેલા દરેક સાપને સ્વતંત્ર એન્ટિટી તરીકે ટ્રેક કરે છે અને ખાતરી કરે છે કે લેવલ 0 બૂસ્ટર્સ સાથે સોલ્વ થઈ શકે.
