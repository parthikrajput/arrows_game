## 1. હેડ્સ-અપ ડિસ્પ્લે (HUD) અને સ્પેશિયલ ઇન્ડિકેટર્સ

Phase 9 ના સ્પ્લિટ અને મર્જર ફીચર્સ માટે HUD માં નીચેના વિશિષ્ટ ઘટકો ઉમેરવામાં આવ્યા છે:

```
+-----------------------------------------------------------------------+
| [PAUSE]   LEVEL 4380 (Normal)        MOVES: 22       [COINS: 18,650] |
+-----------------------------------------------------------------------+
|  [BEAD LOCK: 9/12 SEGMENTS]         [REUNION: HALF 1 OK, HALF 2 PENDING]
+-----------------------------------------------------------------------+
|                                                                       |
|                       [ TWIN RIVERS GAME GRID ]                       |
|           (M401 Merger Pad & M402 Twin Splitter active)               |
|                                                                       |
+-----------------------------------------------------------------------+
|  [HINT (150)]       [SHIELD (200)]       [HAMMER (250)]       [RETRY] |
+-----------------------------------------------------------------------+
```

### મુખ્ય UI ઘટકો:
1. **Bead Lock Progress Bar:** બોર્ડના ટોચ પર કેટલા સેગમેન્ટ્સ બહાર નીકળ્યા છે અને દરવાજો ખોલવા કેટલા બાકી છે તે દર્શાવતો ડાયનેમિક મણકાનો કાઉન્ટર.
2. **Reunion Indicator:** વિભાજીત થયેલા સાપના બંને ભાગોનું સ્ટેટસ (દા.ત. Part A: Exited 🟢, Part B: On Board 🟡).
3. **Twin Splitter Ghost Dots:** જ્યારે ખેલાડી સાપ પર લોંગ-પ્રેસ (Preview) કરે છે, ત્યારે કાંટા પરથી બંને દિશામાં ($90^\circ$ Left/Right) જનારા રસ્તાઓ પર ઝાંખા બિંદુઓ દેખાય છે.
4. **Merger Pad Readiness Glow:** જ્યારે બંને સાપ પેડ પર યોગ્ય સ્થાને હોય ત્યારે પેડ પલ્સિંગ ગોલ્ડન ગ્લો સાથે સક્રિય બને છે.

## 2. વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX & SFX Mapping)

| ઇવેન્ટ / ક્રિયા | વિઝ્યુઅલ ઇફેક્ટ (VFX) | ઓડિયો પ્રભાવ (SFX) | હેપ્ટિક ફીડબેક (Haptics) |
| :--- | :--- | :--- | :--- |
| **M401 Snake Merge** | બંને સાપ ભેગા થતાં જ સોનેરી પ્રકાશનો વિસ્ફોટ (`merge_flash`). | ઊંડો સુમેળભર્યો ચાઇમ (`sfx_snake_merge.ogg`). | મીડિયમ પલ્સ (Double Buzz). |
| **M402 Snake Split** | કાંટા પરથી સાપ પસાર થતાં જ પાણીના ફોરાં અને ચમકતા કણો સાથે બે ભાગ થાય છે (`split_burst`). | ઝડપી વિભાજન અવાજ (`sfx_snake_split.wav`). | તીવ્ર શોર્ટ વાઇબ્રેશન (Sharp Click). |
| **M403 Bead Absorb** | સેગમેન્ટ બહાર નીકળતાં જ તેમાંથી એક ઊર્જા-કણ લોક તરફ ખેંચાય છે (`bead_absorb_stream`). | રણકાર સાથેનો સિક્કા જેવો અવાજ (`sfx_bead_click.wav`). | લાઇટ ટિક (Light Tap). |
| **M404 Reunion Open** | બંને ભાગ બહાર નીકળતાં દરવાજા પરની બે નદીઓ મળી જાય છે અને ગેટ ખુલે છે (`water_gate_open`). | ભવ્ય વોટરફોલ સ્પ્લેશ સાઉન્ડ (`sfx_reunion_water.ogg`). | હેવી હેપ્ટિક પલ્સ (Heavy Pulse). |
| **Split Blocked Bonk** | બેમાંથી એક પાથ બંધ હોય ત્યારે સાપ અટકીને માથું ધુણાવે છે (`bonk_ripple`). | લાકડાના સ્ટમ્પ સાથે અથડાવાનો અવાજ (`sfx_stump_bonk.wav`). | એરર વાઇબ્રેશન (Failure Buzz). |
| **Level 4500 Grand Finale** | સંપૂર્ણ બોર્ડ પર રંગબેરંગી પાણીના ફુવારા અને ગોલ્ડન સાપોનો વિજયી સ્પ્લેશ (`river_convergence_burst`). | વિજયી ટ્વિન રિવર્સ ફેનફેર (`sfx_finale_rapids.ogg`). | સળંગ સેલિબ્રેશન વાઇબ્રેશન. |

## 3. એક્સેસિબિલિટી અને કલરબ્લાઇન્ડ સપોર્ટ (Accessibility)

- **Shape & Texture Divergence:**
  - સ્પ્લિટ થયેલા સાપો પર એકબીજા સાથે સુસંગત પેટર્ન (દા.ત. Part A પર સ્ટ્રાઇપ્સ અને Part B પર પોલ્કા ડૉટ્સ) આપવામાં આવે છે, જેથી રંગ ઓળખ્યા વગર પણ ખેલાડી જાણી શકે કે કયા બે ભાગ એક જ જોડીના છે.
  - Hug Pad પર સ્પષ્ટ હાથ મિલાવતા કે જોડાતા પ્રતીકો (Linked Hands / Nodes) અંકિત છે.
- **High Contrast Borders:**
  - પાણીની બેકગ્રાઉન્ડ પર સાપોની વિઝિબિલિટી વધારવા 2px ઘેરી બોર્ડરલાઇન.
- **Reduce Motion Support:**
  - સ્પ્લિટિંગ અને મર્જર વખતે સ્મૂધ મોર્ફિંગ એનિમેશનને બદલે ત્વરિત કટ-ઇન અને સ્ટેટિક પાર્ટિકલ્સ દર્શાવવામાં આવે છે.

## 4. પર્ફોર્મન્સ બજેટ્સ અને ઑપ્ટિમાઇઝેશન (Performance Budgets)

Phase 9 માં સ્પ્લિટિંગને કારણે એકસાથે સાપોની સંખ્યા વધી શકતી હોવાથી કડક રેન્ડરિંગ મર્યાદાઓ:

| ડિવાઇસ ટિયર (Device Tier) | મહત્તમ એકસાથે પાર્ટિકલ્સ | ટાર્ગેટ ફ્રેમરેટ (FPS) | બોર્ડ જનરેશન બજેટ | મેમરી હેડરૂમ |
| :--- | :---: | :---: | :---: | :---: |
| **Low-End Tier** (Android Go, 2GB RAM) | $\le 30$ particles | 60 FPS (min 50 FPS) | $\le 250\text{ ms}$ | $\le 90\text{ MB}$ |
| **Mid-End Tier** (4GB RAM) | $\le 80$ particles | 60 FPS | $\le 200\text{ ms}$ | $\le 110\text{ MB}$ |
| **High-End Tier** (Flagship devices) | $\le 150$ particles | 60–120 FPS | $\le 150\text{ ms}$ | $\le 130\text{ MB}$ |

- **Entity Pooling:** સ્પ્લિટ થતાં ઉત્પન્ન થતા નવા સાપો માટે ગાર્બેજ કલેક્શન (GC) પ્રેશર ઘટાડવા સ્નેક ઑબ્જેક્ટ્સ પૂલિંગનો ઉપયોગ થાય છે.
- **Level Generation:** L4001–4500 નું જનરેશન $300\text{ ms}$ ની અંદર પૂર્ણ થાય છે.

## 5. ક્વોલિટી એશ્યોરન્સ ટેસ્ટિંગ ચેકલિસ્ટ (QA Checklist P9-QA-01 to P9-QA-10)

Phase 9 ના ઉત્પાદન સ્તરે પરીક્ષણ માટે નીચે મુજબના 10 ટેસ્ટ પાસ થવા અનિવાર્ય છે:

- [ ] **P9-QA-01 (M401 Alignment):** બંને સાપોના હેડ્સ Hug Pad પર સંપૂર્ણ રીતે સ્થિર ન થાય ત્યાં સુધી મર્જર સક્રિય ન થવું જોઈએ.
- [ ] **P9-QA-02 (M401 Body Stitching):** મર્જ થયા પછી સાપના કુલ સેગમેન્ટ્સ બરાબર $A_{\text{len}} + B_{\text{len}}$ હોવા જોઈએ.
- [ ] **P9-QA-03 (M402 Dual-Path Clearance):** જો ડાબો અથવા જમણો પાથ બ્લોક હોય, તો સાપ સ્પ્લિટ ન થવો જોઈએ અને 0 હાર્ટ જવું જોઈએ.
- [ ] **P9-QA-04 (M402 Odd Split Rounding):** 5 સેગમેન્ટ્સવાળો સાપ 3 અને 2 સેગમેન્ટ્સમાં જ યોગ્ય રીતે વિભાજીત થવો જોઈએ.
- [ ] **P9-QA-05 (M403 Bead Counting):** બહાર નીકળતા સાપોના સેગમેન્ટ્સની ચોક્કસ ગણતરી બીડ લોકમાં જમા થવી જોઈએ.
- [ ] **P9-QA-06 (M404 Reunion Trigger):** સ્પ્લિટ સાપનો માત્ર એક જ ભાગ બહાર નીકળ્યો હોય ત્યારે દરવાજો ખુલેલો ન રહેવો જોઈએ.
- [ ] **P9-QA-07 (Undo Integrity):** Undo કરવાથી સ્પ્લિટ થયેલો સાપ પુનઃ જોડાઈને મૂળ સ્થાને પાછો આવવો જોઈએ.
- [ ] **P9-QA-08 (Level 4500 Finale):** લેવલ 4500 પર તમામ સ્પ્લિટર્સ અને મર્જર ગેટ્સ કોઈપણ ભૂલ વગર ક્લિયર થઈને ચેસ્ટ આપે છે.
- [ ] **P9-QA-09 (Memory Leak Check):** સળંગ 50 સ્પ્લિટિંગ લેવલ્સ રમીને રીસ્ટાર્ટ કરતાં મેમરી વપરાશ 120MB થી વધુ ન વધવો જોઈએ.
- [ ] **P9-QA-10 (CI Binary Verification):** `phase_9_meta.bin` ફાઇલનું સાઇઝ વેરિફિકેશન અને ચેકસમ માન્ય હોવું જોઈએ.
