> આ દસ્તાવેજ **Phase 17 (Mongoose Clan: Guardians)** માટે યુઝર ઇન્ટરફેસ (UI), બોસ HP બાર, વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX/SFX), એક્સેસિબિલિટી, પર્ફોર્મન્સ બજેટ્સ અને QA ચેકલિસ્ટનું સંપૂર્ણ માળખું પ્રદાન કરે છે.

## 1. હેડ્સ-અપ ડિસ્પ્લે (HUD) અને બોસ હેલ્થ સિસ્ટમ

Phase 17 ના ગાર્ડિયન બોસ અને સ્પોનર્સ માટે HUD માં નીચેના વિશિષ્ટ ઘટકો ઉમેરવામાં આવ્યા છે:

```
+-----------------------------------------------------------------------+
| [PAUSE]   LEVEL 8350 (Normal)        MOVES: 18       [COINS: 48,500] |
+-----------------------------------------------------------------------+
|  [BOSS HP: ♥♥♥♡♡ (3/5)]     [SHIELD: OFF]     [ROCKS SPAWNED: 1/3]     |
+-----------------------------------------------------------------------+
|                                                                       |
|                     [ OUTPOST GAME GRID ]                             |
|          (M801 Mongoose Twins & M803 Mama Mongoose active)            |
|                                                                       |
+-----------------------------------------------------------------------+
|  [HINT (150)]       [SHIELD (200)]       [HAMMER (250)]       [RETRY] |
+-----------------------------------------------------------------------+
```

### મુખ્ય UI ઘટકો:
1. **Guardian HP Bar:** ગાર્ડિયનના માથા પર તથા સ્ક્રીનના ઉપરના ભાગે લાલ હાર્ટ્સ અને આંકડાકીય કાઉન્ટર (દા.ત. `3/5 HP`) દેખાય છે.
2. **Twin Shared-Link Ribbon:** M801 જોડિયા નોળિયાઓ વચ્ચે જાંબલી લિંક લાઇન ચમકે છે જેથી ખેલાડી જાણી શકે કે બંનેનું આયુષ્ય એક જ છે.
3. **Shield Forcefield Glow:** M802 આર્માડિલો પર વાદળી અર્ધ-પારદર્શક કવચ દેખાય છે જે દર્શાવે છે કે તે હાલ સુરક્ષિત છે.
4. **Rock Spawner Warning Pip:** M803 મામા મોંગુઝના માથા પર પલ્સિંગ એલર્ટ આવે છે: `"Next rock in X moves"`.

## 2. વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX & SFX Mapping)

| ઇવેન્ટ / ક્રિયા | વિઝ્યુઅલ ઇફેક્ટ (VFX) | ઓડિયો પ્રભાવ (SFX) | હેપ્ટિક ફીડબેક (Haptics) |
| :--- | :--- | :--- | :--- |
| **Guardian Hit Damage** | સાપ બહાર નીકળતાં નોળિયા પર લાલ ફ્લેશ અને રૂંવાટીના કણો ઉડે છે (`guardian_damage_flash`). | નોળિયાનો ચીસ અને પીછેહઠનો અવાજ (`sfx_mongoose_hit.ogg`). | મીડિયમ પલ્સ (Medium Buzz). |
| **Shield Deflect** | ઢાલ ચાલુ હોય ત્યારે અથડાતાં વાદળી તણખા ઝરે છે (`shield_deflect_spark`). | ભારે મેટાલિક ઢાલનો રણકાર (`sfx_shield_deflect.wav`). | શાર્પ હેપ્ટિક ક્લિક (Sharp Tap). |
| **Rock Spawn Poof** | મામા મોંગુઝ દ્વારા પથ્થર પેદા થતાં ધૂળનું વાદળ ઉડે છે (`rock_spawn_poof`). | જમીન પર પથ્થર પછડાવાનો અવાજ (`sfx_rock_drop.wav`). | સોલિડ બોંક ફીડબેક (Medium Pulse). |
| **Guardian Retreat Flee** | HP 0 થતાં નોળિયો હસીને જંગલમાં દોડી જાય છે (`guardian_retreat_flee`). | ઝડપી દોડવાના પગલાંનો અવાજ (`sfx_mongoose_scamper.wav`). | વિજયી ડબલ ટેપ (Double Tap). |
| **Guardian Body Bonk** | સાપ ગાર્ડિયન સાથે અથડાતાં માત્ર માથું બોંક કરીને પાછો આવે છે (`guardian_head_bonk`). | લાકડા સાથે અથડાવાનો સામાન્ય અવાજ (`sfx_wood_bonk.wav`). | એરર વાઇબ્રેશન (Failure Buzz). |
| **Level 8500 Grand Finale** | નોળિયા સરદારનો પરાજય થતાં આખા ગઢમાંથી સુવર્ણ કણોનો ભવ્ય વિસ્ફોટ (`clan_fortress_grand_burst`). | ભવ્ય વિજયી આર્મી સિમ્ફની ફેનફેર (`sfx_guardian_finale.ogg`). | સળંગ સેલિબ્રેશન વાઇબ્રેશન. |

## 3. એક્સેસિબિલિટી અને કલરબ્લાઇન્ડ સપોર્ટ (Accessibility)

- **Numeric HP Display:**
  - માત્ર લાલ હાર્ટ્સ પર નિર્ભર રહેવાને બદલે સ્પષ્ટ મોટા આંકડા (દા.ત. `HP: 4/6`) દર્શાવવામાં આવે છે.
- **Shield Silhouette:**
  - ઢાલવાળો ગાર્ડિયન સામાન્ય નોળિયા કરતાં મોટો, જાડા કવચવાળો અને હાથમાં ત્રિકોણાકાર ઢાલ સાથે સ્પષ્ટ અલગ તરી આવે છે.
- **High-Contrast Rock Warning:**
  - જે સેલ પર નવો પથ્થર પેદા થવાનો હોય તે સેલ અગાઉથી લાલ ડોટેડ લાઇનથી હાઇલાઇટ થાય છે.

## 4. પર્ફોર્મન્સ બજેટ્સ અને ઑપ્ટિમાઇઝેશન (Performance Budgets)

Phase 17 ના બોસ એનિમેશન્સ અને સ્પોનિંગ પાર્ટીકલ્સ માટે કડક ફ્રેમરેટ મર્યાદાઓ:

| ડિવાઇસ ટિયર (Device Tier) | મહત્તમ એકસાથે પાર્ટિકલ્સ | ટાર્ગેટ ફ્રેમરેટ (FPS) | બોર્ડ જનરેશન બજેટ | મેમરી હેડરૂમ |
| :--- | :---: | :---: | :---: | :---: |
| **Low-End Tier** (Android Go, 2GB RAM) | $\le 30$ particles | 60 FPS (min 50 FPS) | $\le 250\text{ ms}$ | $\le 90\text{ MB}$ |
| **Mid-End Tier** (4GB RAM) | $\le 80$ particles | 60 FPS | $\le 200\text{ ms}$ | $\le 110\text{ MB}$ |
| **High-End Tier** (Flagship devices) | $\le 150$ particles | 60–120 FPS | $\le 150\text{ ms}$ | $\le 130\text{ MB}$ |

- **Sprite Optimization:** બોસ ગાર્ડિયનના તમામ હાવભાવ અને રીટ્રીટ સ્પ્રાઇટ્સ સિંગલ શીટમાં કમ્પ્રેસ્ડ છે.
- **Level Generation:** L8001–8500 નું જનરેશન $300\text{ ms}$ ની અંદર પૂર્ણ થાય છે.

## 5. ક્વોલિટી એશ્યોરન્સ ટેસ્ટિંગ ચેકલિસ્ટ (QA Checklist P17-QA-01 to P17-QA-10)

Phase 17 ના ઉત્પાદન સ્તરે પરીક્ષણ માટે નીચે મુજબના 10 ટેસ્ટ પાસ થવા અનિવાર્ય છે:

- [ ] **P17-QA-01 (M801 Shared HP Pool):** જોડિયા નોળિયાઓમાંથી કોઈ એકને નુકસાન થતાં બંનેનું સંયુક્ત HP બરાબર ઘટવું જોઈએ.
- [ ] **P17-QA-02 (M801 Dual Retreat):** સંયુક્ત HP શૂન્ય થતાં બંને નોળિયાઓ એકસાથે બોર્ડ પરથી ભાગી જવા જોઈએ.
- [ ] **P17-QA-03 (M802 Shield Invulnerability):** શીલ્ડ લિવર ON હોય ત્યારે ગાર્ડિયન કોઈ HP ડેમેજ ન લેવો જોઈએ.
- [ ] **P17-QA-04 (M803 Rock Spawn Cap):** બોર્ડ પર એકસાથે ક્યારેય 3 થી વધુ સ્પોન્ડ પથ્થર પેદા ન થવા જોઈએ.
- [ ] **P17-QA-05 (M804 Directional Core):** માત્ર નિયુક્ત બાજુમાંથી બહાર નીકળતા સાપો જ ડેન કોરનું HP ઘટાડી શકે.
- [ ] **P17-QA-06 (Zero Damage on Guardian Bonk):** ગાર્ડિયન સાથે સાપ અથડાતાં કોઈ હાર્ટ નષ્ટ ન થવું જોઈએ (0 Hearts Lost).
- [ ] **P17-QA-07 (Undo Guardian HP State):** Undo કરવાથી ગાર્ડિયનનું HP અને પેદા થયેલા પથ્થરો પૂર્વ સ્થિતિમાં આવવા જોઈએ.
- [ ] **P17-QA-08 (Level 8500 Finale):** લેવલ 8500 પર નોળિયા સરદારનો પરાજય થઈને ગ્રાન્ડ ચેસ્ટ એવોર્ડ થવી જોઈએ.
- [ ] **P17-QA-09 (Memory Leak Check):** સળંગ 50 બોસ લેવલ્સ રમીને રીસ્ટાર્ટ કરતાં મેમરી વપરાશ 120MB થી વધુ ન વધવો જોઈએ.
- [ ] **P17-QA-10 (CI Binary Verification):** `phase_17_meta.bin` ફાઇલનું સાઇઝ વેરિફિકેશન અને ચેકસમ માન્ય હોવું જોઈએ.
