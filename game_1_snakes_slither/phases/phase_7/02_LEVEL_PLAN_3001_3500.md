## 1. Principles (સિદ્ધાંતો)
1. **50 Blocks × 10 Levels = 500 Levels:** Levels 3001 થી 3500.
2. **Fixed Difficulty Plateau (D 60–76):** પઝલની મુશ્કેલી રોટેશનલ સિન્ક્રોનાઇઝેશન અને ટાઇમિંગ ચેલેન્જિસથી આવે છે.
3. **Slot Mapping Rule (standard §17.38):**
   - **Block 1 x1 (L3001):** Signature System Intro (Whirlwind Valley & Rotors).
   - **Block 2 x1 (L3011):** Base Mechanic 1 — M301 Island Spinner.
   - **Block 14 x1 (L3131):** Base Mechanic 2 — M302 Turning Hedges.
   - **Block 26 x1 (L3251):** Base Mechanic 3 — M303 Spinning Snake.
   - **Block 38 x1 (L3371):** Base Mechanic 4 — M304 Gear Lock.
   - **45 Variant Blocks:** x1 slots of blocks 3–13, 15–25, 27–37, 39–49.
   - **Block 50 x1 (L3491):** Review Level / "Mastery Mix" (કોઈ નવું item નહીં).
   - **Block 50 x0 (L3500):** Phase 7 Finale ("Whirlwind Summit Shrine") + Jungle Treasure Chest.
