# Phase 13: Level Plan (લેવલ 6001 થી 6500)

> આ દસ્તાવેજ **Phase 13 (Levels 6001–6500)** ના 50 બ્લોક્સ (500 લેવલ્સ) નું સ્લોટ મેપિંગ, બેઝ મિકેનિક્સ અને વેરિઅન્ટ્સ વિતરણ, હેન્ડ-ટ્યુન્ડ લેવલ્સ અને ડિફિકલ્ટી કર્વ નિર્ધારિત કરે છે.

**Related docs:** [Phase 13 Index](./README.md) · [Scope & Rules](./01_PHASE_13_SCOPE_AND_RULES.md) · [Shared Core Standard §17.38](../../SHARED_CORE_STANDARD.md) · [Scaling §3.5, §6](../../SCALING_TO_10000_LEVELS.md)

## 1. 50 બ્લોક્સ માળખું અને સ્લોટ એલોકેશન (50-Block Architecture)

Phase 13 માં કુલ 50 બ્લોક્સ (Block 601 થી Block 650) છે. પ્રત્યેક બ્લોકમાં 10 લેવલ્સ સમાવિષ્ટ છે:

```
Block 601 (6001–6010): Signature System Intro (Mystery Mists Concept)
Block 602 (6011–6020): M601 Scout Gecko Intro (L6011)
Block 603–613        : Variants 1 to 11
Block 614 (6131–6140): M602 Trick Mist Intro (L6131)
Block 615–625        : Variants 12 to 22
Block 626 (6251–6260): M603 Painted Wall Intro (L6251)
Block 627–637        : Variants 23 to 33
Block 638 (6371–6380): M604 Glow Stone Intro (L6371)
Block 639–649        : Variants 34 to 44
Block 650 (6491–6500): Review Level (L6491) + Variant 45 + Grand Finale (L6500)
```

## 4. હેન્ડ-ટ્યુન્ડ લેવલ્સની યાદી (Hand-Tuned Signature Levels)

1. **L6001 (Mist Veil):** હળવા ધુમ્મસમાં 2 સરળ સાપ અને પ્રીવ્યૂનું પ્રદર્શન.
2. **L6011 (M601 Tutorial):** સ્કાઉટ બહાર નીકળતાં જ સમગ્ર કોરિડોર પ્રકાશિત થાય છે.
3. **L6131 (M602 Tutorial):** સાપ નીકળ્યા પછી ખાલી જગ્યાએ ધુમ્મસ પાછું આવવાનો પરિચય.
4. **L6251 (M603 Tutorial):** નકલી દીવાલ: પ્રીવ્યૂ કરીને સાપને દીવાલમાંથી આરપાર કાઢવો.
5. **L6371 (M604 Tutorial):** ગ્લો પ્લેટ પર સાપને ઊભો રાખીને બાજુનો રસ્તો શોધવો.
6. **L6459 (Hard Peak):** 3 નકલી દીવાલો અને ગાઢ ધુમ્મસ સાથે ભ્રામક પઝલ ($D = 85$).
7. **L6491 (Review Level):** તમામ 4 ધુમ્મસ મિકેનિક્સનું સંતુલિત રિવ્યૂ સ્તર.
8. **L6500 (Grand Finale):** 42 સાપો અને રહસ્યમય ફેન્ટમ ફોરેસ્ટમાંથી ભવ્ય મુક્તિ ($D = 91$).
