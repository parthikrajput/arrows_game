# Phase 13: UI and QA Testing Standards (લેવલ 6001 થી 6500)

> આ દસ્તાવેજ **Phase 13 (Mystery Mists: Hidden Info)** માટે યુઝર ઇન્ટરફેસ (UI), ફોગ રેન્ડર લેયર, વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX/SFX), એક્સેસિબિલિટી, પર્ફોર્મન્સ બજેટ્સ અને QA ચેકલિસ્ટનું સંપૂર્ણ માળખું પ્રદાન કરે છે.

## 1. હેડ્સ-અપ ડિસ્પ્લે (HUD) અને ફોગ રેન્ડરિંગ સિસ્ટમ

Phase 13 ના ધુમ્મસ અને ફોગ-ઓફ-વોર માટે HUD અને ગ્રીડ ઓવરલે નીચે મુજબ ડિઝાઇન કરવામાં આવ્યા છે:

```
+-----------------------------------------------------------------------+
| [PAUSE]   LEVEL 6350 (Normal)        MOVES: 16       [COINS: 32,800] |
+-----------------------------------------------------------------------+
|  [FOG CLEARED: 65%]               [SCOUT ACTIVE: GECKO ON BOARD]       |
+-----------------------------------------------------------------------+
|                                                                       |
|                     [ SHROUDED GAME GRID ]                            |
|             (M601 Scout Gecko & M603 False Wall active)               |
|                                                                       |
+-----------------------------------------------------------------------+
|  [HINT (150)]       [SHIELD (200)]       [HAMMER (250)]       [RETRY] |
+-----------------------------------------------------------------------+
```

### મુખ્ય UI ઘટકો:
1. **Fog Alpha Overlay:** બોર્ડના અજ્ઞાત સેલ્સ પર સોફ્ટ વ્હાઇટ-ગ્રે ધુમ્મસની ચાદર (Alpha Mask: 0.85) પાથરવામાં આવે છે.
2. **Tongue-Flick Through-Beam:** જ્યારે ખેલાડી સાપ પર $\ge 350\text{ ms}$ લોંગ-પ્રેસ કરે છે, ત્યારે M603 False Wall પરથી આરપાર જતી સોનેરી પ્રીવ્યૂ લાઇન ચમકે છે.
3. **Scout Gecko Aura:** સ્કાઉટ સાપના માથા પર ચમકતી લીલી ગરોળીનું પ્રતીક હોય છે જેથી ખેલાડી તેને સરળતાથી ઓળખી શકે.
4. **Glow Stone Radiance Area:** જ્યારે સાપ M604 પ્લેટ પર હોય ત્યારે તેની આસપાસનો $3\times 3$ વિસ્તાર નરમ પીળી લાઇટ સાથે ઝળહળે છે.

## 2. વિઝ્યુઅલ અને ઓડિયો ઇફેક્ટ્સ (VFX & SFX Mapping)

| ઇવેન્ટ / ક્રિયા | વિઝ્યુઅલ ઇફેક્ટ (VFX) | ઓડિયો પ્રભાવ (SFX) | હેપ્ટિક ફીડબેક (Haptics) |
| :--- | :--- | :--- | :--- |
| **M601 Scout Clearance** | સ્કાઉટ બહાર નીકળતાં જ ધુમ્મસ ઝડપથી વિખેરાઈને ચમકતા કણોમાં ફેરવાય છે (`mist_dispel_burst`). | સુમધુર પવનનો સુસવાટો અને ચાઇમ (`sfx_mist_clear.ogg`). | સોફ્ટ વાઇબ્રેશન (Light Pulse). |
| **M602 Trick Mist Condense** | ખાલી સેલ પર ધુમ્મસનું નવું વાદળ ઘટ્ટ થઈને પાછું ફરે છે (`trick_fog_condense`). | રહસ્યમય ધીમો વ્હિસ્પર સાઉન્ડ (`sfx_mist_whisper.wav`). | સૂક્ષ્મ ડબલ ટેપ (Double Tap). |
| **M603 False Wall Pass** | સાપ દીવાલમાંથી પસાર થતાં દીવાલ પાણીની જેમ ધ્રૂજીને પારદર્શક બને છે (`false_wall_ripple`). | જાદુઈ પોર્ટલ જેવો સોફ્ટ સ્લિધર સાઉન્ડ (`sfx_wall_phase.wav`). | મીડિયમ ક્લિક (Medium Pulse). |
| **M604 Glow Stone Press** | સાપ પ્લેટ પર ચડતાં જ $3\times 3$ વિસ્તારમાં સોનેરી પ્રકાશ ફેંકાય છે (`glow_stone_ignite`). | દીવો પ્રગટાવવા જેવો ચમકતો અવાજ (`sfx_glow_light.wav`). | લાઇટ ક્લિક (Light Tap). |
| **Hidden Wall Bonk** | ધુમ્મસમાં સાચી દીવાલ સાથે અથડાતાં સાપ અટકીને પાછો વળે છે (`fog_shadow_bonk`). | લાકડા સાથે પછડાવાનો સામાન્ય અવાજ (`sfx_wood_bonk.wav`). | એરર વાઇબ્રેશન (Failure Buzz). |
| **Level 6500 Grand Finale** | સમગ્ર બોર્ડ પરથી તમામ ધુમ્મસ સૂર્યપ્રકાશના કિરણો સાથે વિલીન થાય છે (`sunlight_mist_dissolve`). | વિજયી ફેન્ટમ ઓર્કેસ્ટ્રા ફેનફેર (`sfx_mist_finale.ogg`). | સળંગ સેલિબ્રેશન વાઇબ્રેશન. |

## 3. એક્સેસિબિલિટી અને કલરબ્લાઇન્ડ સપોર્ટ (Accessibility)

- **Fog Density Toggle:**
  - સેટિંગ્સમાં ખેલાડી ધુમ્મસની ઘનતા (Fog Opacity: 50% vs 85%) એડજસ્ટ કરી શકે છે જેથી નબળી દૃષ્ટિવાળા ખેલાડીઓ પણ આરામથી રમી શકે.
- **False Wall Distinct Texture:**
  - નકલી દીવાલ પર ખૂબ જ ઝીણી તિરાડ (Faint Crack) ની પેટર્ન હોય છે જેથી દૃષ્ટિહીન કે કલરબ્લાઇન્ડ ખેલાડીઓ તેને સાચી દીવાલથી સાવ અલગ રીતે ઓળખી શકે.
- **High Contrast Path Preview:**
  - પ્રીવ્યૂ લાઇન 3px જાડી અને હાઇ-કોન્ટ્રાસ્ટ ગોલ્ડન-યલો આઉટલાઇન સાથે રેન્ડર થાય છે.

## 4. પર્ફોર્મન્સ બજેટ્સ અને ઑપ્ટિમાઇઝેશન (Performance Budgets)

Phase 13 ના ધુમ્મસ અને આલ્ફા બ્લેન્ડિંગ માટે કડક ફ્રેમરેટ મર્યાદાઓ:

| ડિવાઇસ ટિયર (Device Tier) | મહત્તમ એકસાથે પાર્ટિકલ્સ | ટાર્ગેટ ફ્રેમરેટ (FPS) | બોર્ડ જનરેશન બજેટ | મેમરી હેડરૂમ |
| :--- | :---: | :---: | :---: | :---: |
| **Low-End Tier** (Android Go, 2GB RAM) | $\le 30$ particles | 60 FPS (min 50 FPS) | $\le 250\text{ ms}$ | $\le 90\text{ MB}$ |
| **Mid-End Tier** (4GB RAM) | $\le 80$ particles | 60 FPS | $\le 200\text{ ms}$ | $\le 110\text{ MB}$ |
| **High-End Tier** (Flagship devices) | $\le 150$ particles | 60–120 FPS | $\le 150\text{ ms}$ | $\le 130\text{ MB}$ |

- **Shader Fallback:** લો-એન્ડ ડિવાઇસ પર કસ્ટમ ગૌસિયન બ્લર શેડરને બદલે પ્રી-રેન્ડર્ડ અર્ધ-પારદર્શક સ્પ્રાઇટ્સ વાપરવામાં આવે છે.
- **Level Generation:** L6001–6500 નું જનરેશન $300\text{ ms}$ ની અંદર પૂર્ણ થાય છે.

## 5. ક્વોલિટી એશ્યોરન્સ ટેસ્ટિંગ ચેકલિસ્ટ (QA Checklist P13-QA-01 to P13-QA-10)

Phase 13 ના ઉત્પાદન સ્તરે પરીક્ષણ માટે નીચે મુજબના 10 ટેસ્ટ પાસ થવા અનિવાર્ય છે:

- [ ] **P13-QA-01 (M601 Scout Sweep):** સ્કાઉટ સાપ બહાર નીકળતાં તેના પાથ અને 1-સેલ રેડિયસનું ધુમ્મસ કાયમી ધોરણે દૂર થવું જોઈએ.
- [ ] **P13-QA-02 (M602 Mist Immunity):** સ્કાઉટ દ્વારા રીવીલ થયેલા સેલ પર ટ્રીક મિસ્ટ ક્યારેય ફરી ન બનવું જોઈએ.
- [ ] **P13-QA-03 (M603 False Wall Pass):** સાપ નકલી દીવાલમાંથી અવરોધ વગર પસાર થઈ શકવો જોઈએ.
- [ ] **P13-QA-04 (M603 Preview Fairness):** લોંગ-પ્રેસ પ્રીવ્યૂ નકલી દીવાલમાંથી આરપાર જતો સ્પષ્ટ દેખાવો જોઈએ.
- [ ] **P13-QA-05 (M604 Glow Stone Area):** સાપ પ્લેટ પર હોય ત્યાં સુધી જ $3\times 3$ વિસ્તાર ખુલ્લો રહેવો જોઈએ; સાપ હટતાં ફરી ઢંકાઈ જવો જોઈએ.
- [ ] **P13-QA-06 (Zero Damage in Fog):** ધુમ્મસમાં અજ્ઞાત અવરોધ સાથે અથડાતાં કોઈ હાર્ટ કપાતું નથી (0 Hearts Lost).
- [ ] **P13-QA-07 (Undo Fog State):** Undo કરવાથી ધુમ્મસનું વિતરણ પાછલા ટર્નની ચોક્કસ સ્થિતિમાં પાછું આવવું જોઈએ.
- [ ] **P13-QA-08 (Level 6500 Finale):** લેવલ 6500 પર તમામ ધુમ્મસ પઝલ્સ ક્લિયર થઈને ગ્રાન્ડ ચેસ્ટ એવોર્ડ થવી જોઈએ.
- [ ] **P13-QA-09 (Memory Leak Check):** સળંગ 50 ફોગ લેવલ્સ રમીને રીસ્ટાર્ટ કરતાં મેમરી વપરાશ 120MB થી વધુ ન વધવો જોઈએ.
- [ ] **P13-QA-10 (CI Binary Verification):** `phase_13_meta.bin` ફાઇલનું સાઇઝ વેરિફિકેશન અને ચેકસમ માન્ય હોવું જોઈએ.
