## 1. 50-Block Architecture
Phase 3 દરેક 10 levels નો એક block ધરાવે છે (કુલ 50 blocks: Blocks 1 થી 50, L1001 થી L1500):
- **Block 1 (L1001–1010):** Signature System Intro — Day & Night Loom (L1001).
- **Block 2 (L1011–1020):** Base Mechanic 1 Intro — M101 Loom Latch (L1011).
- **Block 14 (L1131–1140):** Base Mechanic 2 Intro — M102 Day Bridge (L1131).
- **Block 26 (L1251–1260):** Base Mechanic 3 Intro — M103 Night Pompom (L1251).
- **Block 38 (L1371–1380):** Base Mechanic 4 Intro — M104 Twilight Eyelet (L1371).
- **45 Variant Slots:** બાકીના 45 blocks ના x1 slots પર Base mechanics × 10 craft modifiers ના સંયોજનો.
- **Block 50 (L1491–1500):** L1491 = Review Level ("Loom Mastery", કોઈ નવું mechanic નહીં); L1500 = Phase Finale "Day & Night Tapestry".

## 2. Tier Partitioning & Parameters
| Tier | Levels | Grid Bounds | Threads ($P$) | Obstacles ($O$) | D Target Band |
|---|---|---|---|---|---|
| **P3-A** | 1001–1250 | 12×12 – 13×13 | 28–34 | 8–11 | **60 – 68** |
| **P3-B** | 1251–1500 | 13×13 – 14×14 | 32–40 | 10–14 | **68 – 76** |

- **Difficulty Metric:** $D = 0.6P + 1.5C + 2.0O + 3.0N + 1.0S$.
- **Hard Levels (x9):** દરેક block ના x9 level (L1019, L1029 ... L1499) પર Target $D \approx 84$ ($76 \times 1.10$).
- **Phase Finale (L1500):** Target $D \approx 91$ ($76 \times 1.20$).

## 4. Finale Level 1500 ("Day & Night Tapestry")
- **Layout:** 14×14 craft board featuring the Sun/Moon Cycle, M101 Loom Latches, M102 Day Bridges, M103 Night Pompoms, M104 Twilight Eyelets, and Grand Pincushion Guardian (M049).
- **Target D:** 91.2 (CI verified solvable with 0 hearts and 0 boosters).
- **Rewards:** Unlocks Phase 3 Master Badge, 1,000 Coins, 2 of each booster, followed by L1500 Golden Bobbin Rush.
