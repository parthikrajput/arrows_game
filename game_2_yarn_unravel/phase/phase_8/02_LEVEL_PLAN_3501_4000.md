## 1. 50-Block Architecture
Phase 8 દરેક 10 levels નો એક block ધરાવે છે (L3501 થી L4000):
- **Block 1 (L3501–3510):** Growth Intro (L3501 — Basic Spreading Vine).
- **Block 2 (L3511–3520):** Base Mechanic 1 Intro — M351 Ivy Yarn (L3511).
- **Block 14 (L3631–3640):** Base Mechanic 2 Intro — M352 Snip Tile (L3631).
- **Block 26 (L3751–3760):** Base Mechanic 3 Intro — M353 Seed Bead Thread (L3751).
- **Block 38 (L3871–3880):** Base Mechanic 4 Intro — M354 Blossom Gate (L3871).
- **45 Variant Slots:** બાકીના 45 blocks ના x1 slots પર M351–M354 × 10 craft modifiers ના સંયોજનો.
- **Block 50 (L3991–4000):** L3991 = Review Level ("Garden Knitting Mastery"); L4000 = Phase Finale "The Blooming Quilt".

## 4. Finale Level 4000 ("The Blooming Quilt")
- **Layout:** 14×14 ક્રાફ્ટ બોર્ડ જેમાં 3 આઇવી સ્પ્રેડર રૂટ્સ, સ્નિપ ટાઇલ્સ, સીડ બીડ્સ અને 4 બ્લોસમ ગેટ્સ સાથે આખું બોર્ડ વૂલ ગાર્ડન જેવું ખીલી ઊઠે છે.
- **Target D:** 110.0 (CI pre-validated, 0 hearts & 0 boosters solvable).
- **Rewards:** Unlocks Phase 8 Master Badge, 1,000 Coins, 2 of each booster, followed by L4000 Golden Bobbin Rush.
