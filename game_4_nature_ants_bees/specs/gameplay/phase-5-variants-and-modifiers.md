# Spec: Gameplay — Phase 5 Variants & Modifiers

## Status
Draft

## Type
New Feature

## Goal
Specify the 45 variant slots in Phase 5 (Levels 2001–2500) generated by combining Phase 5 push mechanics (M201–M204) and previous obstacles with the 10 standard modifiers, following the Standard §11 composition formula.

## Current State
Design documented in `phase/phase_5/04_VARIANTS_AND_MODIFIERS_PHASE_5.md` and `SCALING_TO_10000_LEVELS.md` §7, not yet implemented.
- Phase 3 & 4 established modifiers on static and multi-floor boards.
- Applying modifiers to dynamic push blocks, sliding marbles, and hole fillers is introduced in Phase 5.

## Proposed Change
Implement push-modifier bindings in `packages/puzzle_core` across Blocks 3–49 (excluding intro blocks 14, 26, 38):

### 1. Push Modifier Interaction Rules
- `Frozen(K)`: Push block is frozen in place until $K$ adjacent lines exit; cannot be nudged or pushed while frozen.
- `Colored(c)`: Only insect lines matching color $c$ can push this block; lines of other colors bonk against it.
- `Fogged`: Push block or mole hole is shrouded in fog until revealed by clearing adjacent cells.
- `Chained`: Two push blocks are tethered; pushing block A moves block B in the identical vector simultaneously.
- `Countdown(N)`: Push block can only be moved $N$ times; becomes an immutable stone wall thereafter.
- `Phasing`: Block alternates between solid obstacle and intangible ghost block on alternate moves.
- `Armored`: Stone Pumpkin or push block cannot be eliminated by Leaf Blower.
- `Layered(mask)`: Restricts pushing ability strictly to worker bees (`[1]`) or ground ants (`[0]`).
- `Mirrored`: Block cloned across central axis; pushes on one side mirror to the opposing block.
- `Growing(N)`: Brambles expand across sliding paths every $N$ moves.
