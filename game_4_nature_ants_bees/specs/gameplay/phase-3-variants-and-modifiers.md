# Spec: Gameplay — Phase 3 Variants & Modifiers

## Status
Draft

## Type
New Feature

## Goal
Specify the 45 variant slots in Phase 3 (Levels 1001–1500) generated by combining Phase 3 base mechanics (M101–M104) and foundational Phase 1/2 obstacles with the 10 standard modifiers, following the Standard §11 composition formula.

## Current State
Design documented in `phase/phase_3/04_VARIANTS_AND_MODIFIERS_PHASE_3.md` and `SCALING_TO_10000_LEVELS.md` §7, not yet implemented.
- Earlier phases used fixed, hand-crafted obstacle catalogs.
- Systematic on-device variant synthesis (`Base Mechanic × Modifier`) is introduced in Phase 3.

## Proposed Change
Implement the 10 modifier wrappers in `packages/puzzle_core` and map the 45 variant slots across Blocks 3–49 (excluding intro blocks 14, 26, 38):

### 1. The 10 Modifiers & Execution Rules
1. `Frozen(K)`: Instance remains inactive/frozen until $K$ adjacent orthogonal lines successfully exit the board.
2. `Colored(c)`: Restricts interaction to lines matching color $c$; lines of other colors treat it as an empty passable tile.
3. `Fogged`: Instance is covered beneath M010 fog until an adjacent clearing reveals it.
4. `Chained`: Two instances are linked together; state changes on one instantly mirror to the other.
5. `Countdown(N)`: Active for the first $N$ player Moves, then permanently deactivates/collapses.
6. `Phasing`: Toggles active on Even Moves and inactive/intangible on Odd Moves.
7. `Armored`: Immune to Leaf Blower (Hammer) removal; must be opened via in-game logic/switches.
8. `Layered(mask)`: Restricts mechanic effect to specified layer mask (e.g. `[1]` = worker bees only, `[0]` = ants only).
9. `Mirrored`: Cloned symmetrically across the grid's center axis with synchronized state.
10. `Growing(N)`: Expands by 1 cell orthogonally every $N$ player Moves.
