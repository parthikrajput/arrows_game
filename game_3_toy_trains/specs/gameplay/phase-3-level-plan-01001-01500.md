# Spec: Gameplay — Phase 3 Level Plan 1001–1500

## Status
Draft

## Type
New Feature

## Goal
Establish the 500-level progression architecture for Phase 3 (Levels 1001–1500) of Toy Trains: Wooden Railway Puzzle, establishing the fixed difficulty plateau (D 60–76), procedural slot map, onboarding intro slots, L1491 review level, and L1500 Day & Night Grand Central Terminal Finale.

## Current State
Design documented in `phase/phase_3/02_LEVEL_PLAN_1001_1500.md` and `../../SHARED_CORE_STANDARD.md`, not yet implemented.
- Phases 1 and 2 relied on bundled pre-baked JSON files.
- Phase 3 is the first phase generated on-device via deterministic PRNG seeds, demanding strict slot-based generation constraints.

## Proposed Change
Implement the generator configuration and level distribution parameters in `tools/levelgen` and `packages/puzzle_core`:

### 1. Tiers & Difficulty Plateau (D 60–76)
Adheres strictly to standard §17.24: difficulty is capped at a fixed plateau; challenge is generated by mechanic depth and cyclic transitions rather than inflated grid dimensions.

| Tier | Levels | Grid Dimensions | Train Count | Max Obstacles | Difficulty Target ($D$) | x9 Hard Target |
|---|---|---|---|---|---|---|
| **P3-A** | 1001–1250 | 12x12 to 13x13 | 28–36 | 8–14 | **60–68** (Low 60–62.7, Mid 62.7–65.3, High 65.3–68) | 74 ±3 |
| **P3-B** | 1251–1500 | 12x12 to 14x14 | 32–42 | 10–16 | **68–76** (Low 68–70.7, Mid 70.7–73.3, High 73.3–76) | 82 ±3 |

- **L1500 Finale Target:** Target $D \approx 76 \times 1.2 = \mathbf{91 \pm 3}$.
- **Pinch-Zoom / Pan:** Permanently active across all levels (grid $\ge 12\times 12$).

### 2. Slot Mapping Across 50 Blocks
Each 10-level block adheres to the standardized slot rhythm:
- **Block 1, x1 (L1001):** Signature System Intro (`S03` Day & Night Timetable intro level, 0 other new mechanics).
- **Block 2, x1 (L1011):** Base Mechanic M101 Day/Night Gate intro.
- **Block 14, x1 (L1131):** Base Mechanic M102 Day/Night Overpass intro.
- **Block 26, x1 (L1251):** Base Mechanic M103 Day/Night Tunnel intro.
- **Block 38, x1 (L1371):** Base Mechanic M104 Day/Night Livery intro.
- **Blocks 3–13, 15–25, 27–37, 39–49 (x1):** 45 Variant Slots (Base × Modifier).
- **Block 50, x1 (L1491):** Review Level ("Mastery Mix" — 0 new items, complex multi-mechanic synthesis).
- **Block 50, x0 (L1500):** Milestone Finale "Day & Night Grand Central Terminal".

### 3. Solvability & Reverse Construction Rules
- Every seed must be mathematically verified as solvable with 0 hearts lost and 0 boosters used.
- Intro levels (x1) are restricted to the introduced mechanic plus at most 1 earlier mechanic to ensure pedagogically clean onboarding.
